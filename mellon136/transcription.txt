# Beinecke Mellon MS 136, "Das zweyte Silentium Dei" (1798): every cipher passage
#
# Conventions
# - Each cipher sign is written as its value in the book's own key (p. 83, "Die Figur unserer geheimen Schrift"):
#   a pigpen-type grid in which each cell shape stands for two letters, the second marked with a dot.
#   Grid (shape = plain / dotted):  ┘ a/b   ⊔ c/d   └ e/f   ⊐ g/h   □ i   ⊏ l/m   ┐ n/o   ⊓ p/q   ┌ r/s
#   Cross cells:  V t/u   > v/w   <· y   Λ z  (x, the dotted Λ, is added in pencil on p. 83 and not used).
# - Ligature signs from the table beside the figure are written in brackets: [ae] [oe] [ue] [ch] [ck] [sch] [ss]
#   [st] [th] [und] [ll] [nn] [tt] [ff]. A double stroke over a sign doubles it and is written as the ligature.
#   Ligatures are marked where they were seen; a missed ligature changes the sign count, not the reading.
# - Clear script inside a passage (Latin capitals A. B. C., numerals, planet and element signs) is in ( ).
#   (∇) water, (☉) Sun/gold, (☿) Mercury, (∴) sand; {?} a sign not read.
# - "No." in cipher is the sign ┐ followed by a colon-like dotted ┐: written n o.
# - '=' is the scribe's line-end or compound hyphen. '|' is a line break inside the passage.
# - Page numbers are the manuscript's pagination; Yale canvas ids in NOTES.md.
#
# Read from Yale Digital Collections IIIF full-resolution images (5310 x 3260), 22 Sept 2026.
