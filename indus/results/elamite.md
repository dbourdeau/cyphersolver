# Proto-Elamite: numeral systems and what they count

- entries with a number and a sign before it: 6274 (capacity system 1250, counting systems 5024).
- commonest counted signs, capacity: M288 x265, M297 x196, M036 x62, M002 x36, M010 x34, M243 x33, M218 x31, M106 x27.
- commonest counted signs, counting: M288 x492, M346 x238, M263 x176, M218 x165, M376 x159, M054 x159, M367 x122, M371 x117.
- Jensen-Shannon divergence between the two: 0.362 bits; label permutations as large: 0 of 500.
- Indus, short against long strokes at the same values (structure.py S1): 0.592 bits, 0 of 1000.

Proto-Elamite writes different numeral systems for different kinds of thing, and the Indus two stroke series behave the same way to a comparable degree: the property is shared with the script that is thought to have given the Harappans the idea of writing. It says the Indus numerals are an accounting device of the same family, not which language lies behind them.
