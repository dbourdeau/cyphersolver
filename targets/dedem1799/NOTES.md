# Van Dedem (Constantinople) to the Burger Agent van der Goes, No. XVIII, 26 Aug 1799 — DECODE R1895

Status: in progress — the system was identified from the images; the code groups have not been transcribed, and no
key is known.

Split on 14 Oct 2026 from `../dedem1788/` under the one-key rule (George Lasry, 14 Oct 2026). Catalogue entry 225
grouped this letter with Van Dedem's 1788–93 despatches to Van de Spiegel (R2120, R2122, R2131), which are in a
homophonic word code laid out alphabetically in 500-group blocks: a different cipher with its own page
(`docs/dedem1788.html`). This one is in a marked code. Worked 2026-09-21 as part of the joint entry.

## The record

NA The Hague, 2.01.08 (archief M. van der Goes), inv. 346; DECODE R1895, dated there 1799-08-26. No. XVIII,
"Duplicaat", to the "Burger Agent" (Maarten van der Goes, Agent of Foreign Affairs of the Batavian Republic), dated
26 Aug 1799. Four images: P1 is an unrelated clear page signed Schimmelpenninck (a misfiled leaf, to report to
DECODE); P2 opens with the heading and about eleven lines of code; P3 is in clear; P4 is more code.

The code: two- and three-digit groups separated by points, many with superscript marks (×, ″, ¯, ~) and some
underlined, the style of Croiset's marked nomenclators. It is not the 1788–93 Dedem code (groups up to 3839, no
marks). No key for it is on DECODE.

Images: `.worktrees/dedem1788/dedem1788/img/IMG_R1895_I9368_P1.png` … `I9371_P4.png` in the main checkout
(git-ignored; also under `targets/vanreede1787/decode/`). Site figure `docs/dedem1799_p2.jpg` (P2, turned upright).
