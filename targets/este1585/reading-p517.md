## Why each probable word is probable (decoded letters -> reading)

- L1 `vous e au[faire]ir` -> **avoir**: the barred dumbbell taken as a null (Tomokiyo) and the Venus sign as o (K-C01), not K-C02's [faire]. L1 `?e e ci·pt` -> **escript** (one shape not identified). L2 `ddstre` -> **d'estre**. L2-3 `perse|oue` -> **personne**.
- L6 `gueme au` -> **guerre** (ss read rr); L6 `1e` -> **se** (the lone stroke `1` as s).
- L12 `pmues|crire` -> **peu escrire**: the second pass read e (zs) where the arbitration kept ss.
- L13 `lem nn r|eschal` -> **le mareschal**: the sign kept as newt is the barred c (eps = a) of the other passes.
- L14 `lieum` -> **lieux** (S as x, as on p. 436 "deux"). L17 `l?odeue` -> **Lodeve** (one ink blot). L18 `feu[fait]t` -> **feust** (A here is not "fait").
- L20 `la[qui]iuqd` -> **l'arrivée** (the doubtful ȝ as r; `x o` = ée, as in "levée" L24 and "créé" p. 523). L21 `l nn ntention` -> **l'intention**; `pouloict` -> **pouvoit**.
- L24 `leuqd` -> **levée**; L25 `mid` -> **mil**. L26 `lesqued ss econ d` -> **lesquels selon**; `?ominion` -> **opinion**.
- L28 `m[faire] sem?le` -> **m'a semblé** (two dots = the three-dot b, one dot faint; Venus sign here a). L29 `c[qui]hoe s?es` -> **choses** (code sign and two shapes as nulls).

Restored: **Espagne** twice (the code word `y`, also on p. 523, where it stays unread) - "letres du Roy d'{y}" and "escript en {y}"; the sense
and Montmorency-Damville's known dealings with Philip II in 1582-1589 make Spain likely, but `y` has no value in any key, so it is not counted.
**que** (L29 `q?e`). Unresolved: the end of L4 (`de t…`, perhaps the court of Turin) and the last words of L29, which run on to p. 518 (not read).
