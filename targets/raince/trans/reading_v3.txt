# Raince, BnF fr. 2984: the reading of the ciphered residue (v3, 5 Oct 2026)

v3: every one of the 106 lines re-read off the numbered-token images (img/idx/, regenerated
from fresh Gallica natives) against the measured key, using the machine labels (show.py) as a
first guess and correcting each against the glyphs. Lines so re-read are marked R. Word signs
are expanded in brackets: [roy] [pape] [le pape] [l empereur]; [X] = the two-crossbar sign
(Remaining gaps); [X2] = the four-armed circled cross, not in the key. ? = unresolved.
Measured with measure_sense.py (period-French lexicon; ?, (?) and bracketed signs count unread).

Each line is given twice: `H` = read glyph by glyph off the microfilm against the
measured key, one character per segmented token (gold/labels.txt); `M` = the machine
decode (classifier + period-French 6-gram beam, draft9.txt) for lines not yet read by
hand, which is right on about 85-90 % of letters and is NOT a reading. `?` = a token
that did not resolve; word spacing is supplied by a lexicon segmenter and is a reading
aid, not evidence. Lines run on: a word broken at a line end continues on the next.
