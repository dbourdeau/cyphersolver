# LABEL SHEET, doc 627 control (neutral labels, shape words only)

Each cipher sign has one neutral label (S01, S02, ...). Labels carry no meaning; their order is random.
Write one token per sign: the label, then, if the sign carries one small digit written above or after it (superscript), `^` and that digit as written, e.g. `S07^3`.
Numerals written as numbers: `#` and the number as written, e.g. `#14`. A run of four or more digits: split it into the two-digit groups you see (e.g. `#15 #19`); add `?` to any split you doubt.
One point or full stop between groups: `.`  Unlisted shape: `NEW1`, `NEW2` ... and describe it in BLIND_NOTES.md. Doubt: trailing `?`, e.g. `S12?` or `S07^3?`.
