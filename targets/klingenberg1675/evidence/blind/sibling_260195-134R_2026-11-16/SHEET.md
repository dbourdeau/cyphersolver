# Label sheet: the Klingenberg German code of 1675 (names only)

You are writing down what is on the page, not what it means. This sheet gives names for the drawn signs.
It gives no values, and you must not try to work any out.

## What a cipher run looks like

These are Conrad Biermann's own drafts (rough hand, many deletions). Clear German alternates with runs of
numbers (mostly 2-3 digits) and drawn signs, usually separated by commas. Runs can fill whole pages.

## How to write tokens

- Numbers: write the digits exactly as seen (`78`, `414`, `507`). Do not "correct" a figure.
- Drawn signs: write the label from the table below, exactly as given (upper and lower case differ).
- Separate tokens with a single space. Keep the writer's order. Ignore row-end hyphens.
- `~` straight after a token = you are unsure of it. `?` alone = unreadable token. `?5?` = number with
  unreadable figures. `BLOT` = a group hidden by an ink blot.
- `"` after a token = two dots (umlaut-like) written over it.
- Struck-out words, numbers and filled blots are deletions: write `[struck]` at their place (with what you can
  see inside the brackets if legible) and carry on.
- Inserts (margin or between lines) with a mark: write them where the mark puts them, as `[insert: ...]`;
  without a mark, put them at the end of the page as `[margin: ...]`.
- Show-through from the other side of the leaf (mirror writing) is not text: skip it.
- A sign not on this sheet: describe it briefly in braces, e.g. `{small t with crossbar}`.

## Sign labels (form only)

| label | form |
|---|---|
| # | large double-barred hash sign (two bars) |
| H | small single-bar sign (H-like, one bar); count the bars on every hash-like sign |
| - | dash sign standing as a token |
| A | plain lambda / caret |
| K | lambda with an extra stroke (hooked) |
| B | beta / ß-like looped sign |
| C | bracket '[' with no middle bar |
| V | Γ / '[' sign with a top bar (distinct from E) |
| E | E-like sign with a middle bar |
| D | d with a cross stroke |
| w | w-shaped sign (in some hands a plain d without stroke: write `d` for that and say so) |
| F | q-like sign with a straight descender and a cross |
| G | g-like sign with a curled tail (script 9 / g) |
| I | I-like stroke sign |
| J | ']'-like sign |
| L | small L-like sign |
| M | pi / m-like triple-stem sign |
| O | big O |
| o | small o |
| 0 | O written like the digit zero (write `0`, it is a known slip) |
| P | single cross (+) |
| PP | double-barred cross (‡) |
| Q | q with a crossed tail |
| T | big T-like sign |
| ⊥ | inverted T |
| U | reversed bracket (like ⊐) |
| X | plain saltire (x-shaped cross) |
| x | small cursive x |
| y | y-like sign |
| Z | small 2-like sign |

Caution: the forms for I, T, y and w are not described in the repository; they are given here from the label
names only. F and Q are both q-like: F has a straight descender with a cross, Q a crossed tail. If you cannot
tell them apart, write `F~`. Use `{...}` for anything that fits no row.

The labels are the repository's own sign names for this key (targets/klingenberg1675/key.tsv, kind = sign) with
the forms described in its transcription headers. Where earlier readers used two forms for one label (for
example K), the drafts-hand convention of reader b175 is used here.
