# Key sources: three other telegrams of the same code, each with its plain text

These are the sources of `key_frozen.tsv`. Each pairs code words with plain words on the same sheet. One pass from
the full images and one from zoomed crops; `?` = not certain. Code words in **bold** are the ones that stand for
another word; the rest of each telegram is clear Spanish.

## 9922: Núñez to Limantour (Hotel Pupp, Karlsbad), Mexico 10 Aug 1899 (CDLIV.1a.1883.38.9922)

Austrian telegram form, typed strips; handwritten translation below on the same form.

Code: **remero flagrame emanarle sabio ducado** se **pizquen** con **cotorro** nacional **creativos** servicio
**ovejuno final divagaria** si posible dejar **igualo matad virar hilazas** en **czarina** o **cotorro** que heine
**mullidor** tipo sin perjuicio **sonsonete impulsese** siempre **desvario cotorro** nacional para **besarsele desague
desgracia baldearia** sin duda tipo **cultivo** = nunez

Translation (on the form): Presidente me encarga decirle que cuando se pacten con Banco Nacional bases servicio
nuevo empréstito, convendría si posible dejar Gobierno libertad tomar fondos en casa ó Banco que Heine mejor tipo,
sin perjuicio remisión hágase siempre conducto Banco Nacional para abonársele comisión; competencia abarataría sin
duda tipo cambio.

## 9929: Limantour (Trouville) to Núñez, 28 Aug 1899 (CDLIV.1a.1883.38.9929)

Draft on squared paper: plain text on the left with the words to be coded underlined, the code words on the right,
on the same line as the plain words. This is Limantour's answer to 9926.

| plain (underlined words) | code |
|---|---|
| No urgiendo resolver asunto | supurar consulto |
| Depósito Banco Inglaterra | emulsion cotorro |
| informaréme modo más | oasis morillo |
| conveniente hacerlo | dimmo? impulsarlo |
| Paréceme imposible que | doblame interino sabio |
| impresión Títulos E.U. | intestino villanos |
| origine dificultades que | pinche estorbos sabio |
| Presidente teme, pero como | remero vela, puñal desalado |
| Casa Morgan insiste mucho | czarina leva oda |
| en esa condición, bueno sería | desuello, crinejo kinglaria |
| que Embajada Mexicana | sabio federal multitud |
| Washington trate asunto | zapee consulto |
| con ella, procurando también | dictador fausta, respirando uraño |
| que se interese en obtener | sabio finca parar |
| mayor reducción posible | mostrenco sifon redigamo? |
| en costo | finca doncel |

Plain text in full: Estoy aquí alojado Villa Belchamps. Punto. No urgiendo resolver asunto Depósito Banco
Inglaterra, informaréme modo más conveniente hacerlo. Punto. Paréceme imposible que impresión Títulos E.U. origine
dificultades que Presidente teme, pero como Casa Morgan insiste mucho en esa condición, bueno sería que Embajada
Mexicana Washington trate asunto con ella, procurando también que se interese en obtener mayor reducción posible en
costo. Limantour

## 9930: Núñez to Limantour (Trouville), Mexico 31 Aug 1899 (CDLIV.1a.1883.38.9930)

French telegram form (Trouville stamp 31 Aout 99), 80 words, and a separate "Traducción" leaf in the same record.

Code: indice vario camacho emandole queda abrego corchado pleno / insanar coarina? morgan mande intitular crimenes /
finca estados unidos litiandose pleno sabio czarina / amp. resora sigile coseo finca lo. posible finca limadura? /
sabio igualo mexicano pleggiara? importe intistono? al / segregarte crimenes finca mexico veringa huinero? stop /
ancas? ronco nanta al cocer baba ventajas divan turbamos / todas las defines agil opio hicimos parrafo gamela sino
hechizo / parrafo [colmillejo, colz. struck out] colmillejo / como abrego jirpeo cultivans tambien las ?zedilla
abandonas planchas / nunez

Translation (leaf 3): Hoy telegrafío Camacho diciéndole: Queda Ud. autorizado para decir Casa Morgan mande imprimir
Bonos en E.U., interesándose para que Casa impresora reduzca costo en lo posible, en inteligencia que Gobierno
Mexicano pagará importe impresión al recibir Bonos en México Tesorería General. Stop. En proyecto mensaje, al aludir
á ventajas Conversión, suprimimos todas las Cifras y no hicimos párrafo especial sino final párrafo anterior como
Ud. indicó, cambiando también las 3 últimas palabras.

Pairs not used in the frozen key because the reading of the code word is too uncertain: pleggiara? (pagará),
intistono? (impresión), huinero? (General), ancas? (En), ?zedilla (3).
