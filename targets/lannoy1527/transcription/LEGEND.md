# Sign legend for the Soria → Lannoy letter of 7 March 1527 (Estense, Autografoteca Campori, Lettera L, cc. 9-12)

One token per sign or code group, separated by spaces. Clear (uncoded) Spanish words are written inside braces,
e.g. `{y han me dicho}`. Unsure tokens end in `?` (e.g. `tz?`), illegible ones are `??`. Line breaks follow the
manuscript; each line starts with its label `L07:` (the label printed in red on the strip images in
`crops/lines/<leaf>_Lnn.jpg`).

## Code groups (three or two Latin letters written as a word)

Write them exactly as the letters read: `lab`, `leb`, `den`, `dan`, `dun`, `dri`, `pre`, `ral`, `zal`, `gis`, `ges`,
`gog`, `mor`, `mur`, `mir`, `com`, `cem`, `cam`, `tem`, `ten`, `tan`, `fip`, `fib`, `sim`, `sem`, `bel`, `pof`,
`loe`, `lue`, `lie`, `zer`, `pax` ... If a letter of a group is unsure, mark the whole group, e.g. `leb?`. A group
whose last letter is the looped e (as in `loe`, `lie`, `pre`) keeps the plain letter `e`.

## Single signs

| token | what it looks like |
|---|---|
| `4` | the figure four |
| `3` | the figure three (a z-like 3 with a tail below) |
| `5` | a 3 with a short stroke or bar on top (like ꝫ / 5) |
| `7` | a horizontal bar with a stroke going down from its right end (like ⁊ or a flat 7) |
| `j` | a reversed c / ɔ shape crossed by a horizontal stroke (looks like a small "ↄ" with a bar or a hooked 7) |
| `<` | an angle open to the right (∠, like a "less than") |
| `o` | a small open rectangle or box (⊏ / □), drawn flat |
| `e` | a large looped c-like sign (ꞓ, a C with an inner loop) standing alone |
| `s` | a small s |
| `tz` | a ligature like "tc" or "tz" (a t whose foot curls into a z/c); one sign |
| `tt` | two crossed t's joined with a bar (ꝥ, often followed by a tail like "y"); one sign |
| `#` | a double cross (two verticals crossed by two horizontals) |
| `+` | a plain cross |
| `+=` | a cross with an extra bar on top (∓, like a double-barred dagger) |
| `d` | a round d with a stroke through the ascender (ð / ∂ / ꝺ) |
| `L` | a capital L |
| `X` | an x or cross with a loop or flourish (Ꭓ, ✗ with a curl) |
| `*` | an asterisk or star-like cross |
| `$` | a struck sign like £ or an E crossed by a long stroke |
| `11` | the figure eleven (two vertical strokes, often with a dot) |
| `g#` | a g followed by a double cross (written together) |
| `A#` | a capital A with a double cross or bars |
| `-o-` | a small o between two dashes |
| `/6/` | a figure between slashes (keep the figure: `/21/`, `/9/` ...) |

If you meet a sign not in this table, give it a short new token (letters or symbols, no spaces), add it to the
"new signs" list at the top of your file with a description and the line where it first occurs, and use that token
consistently.
