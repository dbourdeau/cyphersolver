# peking1912: reading

Chinese text with punctuation (a Chinese telegram has no stops; the punctuation is ours). {x} = doubtful code.

## Peking telegram, received at Simla by 3 October 1912 (NAI, Foreign Dept., Deposit Cypher 1912, Nos. 86-87, p. 6)

電悉。大總統早經允准復回達賴名號，並允到京，格外歡迎優{徇 → 待}。是否通過，速覆。

Code 1770 gives 徇 as written; read 待 (1769), one digit away, which gives the set phrase 優待 "generous treatment"
(the General Staff's translation of 1912 also has "generous treatment").
