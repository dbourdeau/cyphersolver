#   python3 scripts/decode.py transcription.txt
# CAPITALS = decoded cipher words; {n} = nomenclator code (not identified); [ ... ] = clear text of the letter; ?n = number out of the
# alphabet. Misread numbers are left as they come out (e.g. RACQUET for pacquet, BLRT for bort on image 78); the reading by sense, with every correction justified, is reading.md.
