# Prior proposals, scored (11 Nov 2026)

Scoring rule (stated, not a validation):
- **anchored** = letters inside a contiguous run that matches a corpus formula (tools/corpus.py FORMULAS, initials or
  standard nomina sacra) or a published sibling-family element (DX, SCS, IS, DIC, BENED, O invocative);
- **free** = letters given a word chosen by the proposer with no parallel;
- **broken** = letters whose reading depends on the BL-2015 transcription errors (#10 R, #11 G).
An acronym "reading" has no unicity: with ~30 Latin words per initial in a pious vocabulary, any 18-letter string
gets a fluent gloss (the shuffled strings in RESULTS.txt get the same formula-run scores as the real one). Only
parallels (the same letter order on other blades) carry evidence; meaning stays the family authors' conjecture.
