# Sign names for c. 44r (shape names only, no values)

Written before the key was built. ASCII names, one token per sign; signs written joined to a following `o` or
curl and always seen joined are one token. Mark suffixes: `'` one dot above, `:` two dots above, `,` dot below,
`-` bar above, `_` bar below, `/` stroke through.
