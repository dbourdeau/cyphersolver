# Label sheet: the Petkum/Paulmyer French number-and-sign code (names only)

You are writing down what is on the page, not what it means. This sheet gives names for the drawn signs.
It gives no values, and you must not try to work any out.

## What a cipher run looks like

Inside clear French, the writer puts runs of numbers (1 to 3 digits) and drawn signs, usually separated by
commas, full stops or small gaps. A run can be one group (for example a lone number standing for a name) or
several lines long.

## How to write tokens

- Numbers: write the digits exactly as seen (`14`, `201`, `356`). Do not "correct" a figure.
- Drawn signs: write the label from the table below, in capitals as given (`ct` is lower case).
- Separate tokens with a single space. Keep the writer's order.
- `~` straight after a token = you are unsure of it (`356~`, `MT~`).
- `?` alone = a token you cannot read at all. `?5?` = a number with unreadable figures.
- `[struck]` = a token or group the writer struck out (write what you can see inside the brackets if
  legible, e.g. `[struck 204]`).
- `[gloss]` = any writing in another hand between the lines or in the margin. Note it, do not copy it.
- A sign not on this sheet: describe it briefly in braces, e.g. `{8-like}` or `{plain m}`.

## Sign labels (form only)

| label | form |
|---|---|
| ct | ct ligature |
| LL | looped double l |
| B | b-like sign |
| X | x-like sign |
| PSI | psi / 4-with-tail sign |
| BET | beta / ß-like sign |
| MT | m with a tail |
| QX | crossed q / 2-with-tail sign |
| LAM | lambda |
| T | small T |
| Y | y-like sign |
| G | looped g |
| Q | plain q with a straight tail (9-like) |
| TH | theta |
| HSH | #-like (hash) sign |
| U4 | u4-like sign |
| HB | barred h |
| PF | crossed p-like sign |
| DB | crossed d |
| FF | ff-like sign |
| PM | plain m standing inside a run (seen in Paulmyer's hand) |
| E8 | 8-like sign inside a run (seen in Paulmyer's hand) |

The labels come from the repository's own label set for this code (targets/petkum1665, key files and
`gloss/sign_convention_b186_blind.md`). PM and E8 are names given here for two forms that the repository
notes in Paulmyer's hand without a label.
