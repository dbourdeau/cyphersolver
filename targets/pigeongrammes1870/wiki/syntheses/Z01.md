**Where the work stands (7 Nov 2026).** The inspectors' table is an alphabetical lexicon ([[C001]]); words spelled between beacons are the reliable class ([[C002]], [[C031]]: 4 of 4 blind, but with thin margins); ordinary words need context the telegram does not supply by itself. Coverage of the telegram: 12.5% of 608 coded (non-beacon) group occurrences have an accepted reading (20 supported entries, all assigned by hand from the printed heading, the blind genre check and the name tests; none by the engine).
For the Favre / delegation code only vocabulary tied to date and topic is firm ([[C026]], [[C027]]); the code is not alphabetical ([[C022]]).

**What the rebuilt process established (the loop in PROCESS.md, `tools/engine.py`).**
- A calibrated gate: blind on the gold units it accepts nothing it should not, and (with the context requirement) nothing at all ([[T13]]).
- Two false-acceptance episodes found by review and rolled back, each producing a rule ([[C032]], [[C033]]); see `log.md`.
- After the fix: 355 units proposed, 0 accepted, stop after 3 loops. The best near-misses are recorded as hypothesis claims (C100-C105: 4914 = la, 2207 = de, 6402 = par, 1007 = bien, 9526 = une, 9904 = vous) with the evidence each would need. None is accepted.
- Conclusion: from the telegram alone, with the current knowledge, the gate cannot add readings. More knowledge has to come from outside the data, ranked below.

**Next evidence, ranked by what it would unlock.**
1. Pillon on the beacon pairs ([[Q03]]), the other recipient ([[Q02]]) and the Nantes/Rennes names ([[Q01]]): the spelled-name class is the only one that decodes reliably, and its meaning and anchors are the open points.
2. Piece-level consistency across spelled runs ([[Q08]]): a testable prediction (BAL-L-ON from 6129 = ON); implementing it is the next engine change.
3. A domain language model from the telegraph administration's own text ([[Q04]], Steenackers 1883) to lift ordinary words ([[C031]]).
4. A second text in the inspectors' code, or the Algeria 'chiffre des inspecteurs' telegrams in ciphertext: cross-validation of the lexicon and a real test set.
5. Run the same engine on the Favre pages with date profiles ([[T05]]): not built yet.
