Two engine runs showed it. Run 1 (gate: margin >= 2, null, replicate) accepted six unsupported units (de, vous, et, la, le, insurrection). Run 2 (added: context margin >= 3) still accepted `5021 2704 = le` spelled l|e. The margin null does not control for positions that sit next to a very common word, so a function word wins whatever the context. Rule now in the engine: context margin >= 3 nats over the runner-up, spelled units only for beacon-bounded runs ([[C033]]), spelled words of at least 4 letters. See `log.md` (two rollbacks).
