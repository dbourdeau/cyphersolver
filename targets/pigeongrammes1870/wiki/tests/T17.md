`domain_test.py`. Prior = log(lam*P_topic + (1-lam)*P_general) with the topic corpus = Dagron 1871 + the 1872 Societe d'acclimatation article (23,433 words; pigeons 231, ballon(s) 61, depeche(s) 164, bataillon 0, sante 0, portante 0). Benchmark as in T02 (10 supported items, MRR).
lam 0: MRR 0.6146 (ballon rank 13); lam 0.25: 0.7066 (ballon rank 1; sante 87 -> 117, portante 468 -> 488); lam 0.5: 0.7058. The topic prior resolves ballon vs bataillon, the case position and fixed pieces could not ([[T14]]); it does not help words absent from the topic corpus. Supports [[C039]].
