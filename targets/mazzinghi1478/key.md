# Mazzinghi 1478/79 cipher: provisional key

Recovered from MAP 89/142 itself (solver run, then word-by-word reading), cross-checked against one glossed run of the
sibling MAP 72/170 ("publichamente mostra lectere" over `pq=6so+8xnHx 8r4Hr+ 4xHx6e`). Monoalphabetic substitution with
letter-like signs, word division kept, numerals for persons, a barred p for *per*, clear words between runs.

Sign names are the ASCII stand-ins used in `transcription_89_142_v1.txt` and `reading_89_142.txt`.

## What is not settled

* Several classes are almost certainly two or three distinct signs that the 1272-px scan does not separate: `o` (d / c / q),
  `4` (s / l), `H` (t / h), `b` and `6` (r / v / l / f), `q` (u / s in *casa*, *imbasciadori*). The readings choose the value
  from context; a higher-resolution image or a sign-by-sign key rebuild from the glossed sibling MAP 72/170 should split them.
* Numerals 2, 3, 10, 12, 30, 40 stand for persons ("la morte del 30", "10 gli ha bandito", "lettere del 40"). Not identified.
* `olop`, `ov+`, `cop`, `oxP` look like abbreviations or code groups (`op` = *papa*? cf. the sibling's `delop` under the gloss
  "del papa").
