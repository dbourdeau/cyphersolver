Steps:
1. Download the images to `sources/raw/cehm1462b_2026-11-26/images/` with SHA256SUMS.
2. For each candidate, transcribe the coded groups first (no key lookup), save and hash. Then transcribe the period
   decipherment (pencil or ink gloss, or a typed decipherment) separately, save and hash.
3. The test applies only to a telegram whose coded part is written in two-digit groups (00-99). For any other form
   (letters, three- or four-digit groups, code words) the result is "not applicable" and is recorded as such.
4. Decode every applicable telegram with K-SYL RC exactly as transcribed by Jalkut; no cell changed, nothing added.
5. Measure A (agreement): both the decode and the period decipherment are normalised (lower case, accents removed,
   letters only, h removed, v -> b, k -> c, ll -> l, rr -> r) and compared with Levenshtein distance:
   A = 1 - dist / len(normalised period decipherment). Only the stretch covered by the period decipherment is used.
   If the decipherment covers only part, that part is compared to the matching groups, aligned by a free-end
   alignment (the best-scoring substring of the decode).
6. Controls: 1,000 permuted cards (the 100 cell values shuffled, seed 1462), same measure.
7. **Pass** for a telegram: A >= 0.80 and A greater than every control. **Card confirmed as a key of the time** if at
   least one applicable telegram passes. If no telegram applies, the held-out check could not be made (stated as such).
   If one applies and misses, that is reported first and the Ornelas reading's standing is reduced accordingly.
8. Also recorded: the office and date of each held-out telegram, to see whether the card's users are the same office
   (Chihuahua government / Jefatura de Armas, Ciudad Juárez) and period (1914) as Ornelas.

- **A3 CMXV.35.3464.1 (Carbajal, code words).** Search the digitised code books for the code words that are not
  Spanish dictionary words (dulixio, duquesnes, cerodos, contenderque, escandalara) and the rarer real words used as
  code (heliometro, apretaderas, sobreverterse, colmillada, pinula): full-text search of HathiTrust and the Internet
  Archive, and a web search. Pass: a code book is found whose entries include at least three of these words; then its
  values are applied as printed. Otherwise: "no code book found".

  alphabetical word list). For the five non-dictionary code words this cannot hold, so if they are present the test is
  declared failed without a run.
- **A4 CMXV.18.1770.1-4 (Bonilla, two ten-digit runs).** Keys not tried on 25 Nov: (i) Clave No. 0's letter grid read
