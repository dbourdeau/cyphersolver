# Transcriptions

- `R1_A` ... `R5_A`: pass A, read forward, one file per image (`imgNNNN` = item 93 vol. 1 image N; `m332_NNNN` = M332
  roll 2 image N). Each run starts with the clear words before and after it; numbers are written `number/gloss` where a
  contemporary letter is seen over the number, `?` marks a doubtful figure or gloss. `inventory.tsv` in each folder lists
  the pages screened.
- `R1_B` ... `R5_B`: pass B, made independently by other agents, reading each page backward (from the last number, right to left, bottom line to top) and writing the lines in page order.
  Ranges of cipher pages: R1 = images 16-35; R2 = 39-90; R3 = 108-242; R4 = 253-493; R5 = M332.
- `reconciled/`: the numbers per document after the two passes were aligned and their disagreements settled on the
  image (decisions in `../readings/*.md`). `<id>.txt` is the principal copy, `<id>_copies.txt` the other copies.
- `second_agent/`: four passages and a count check transcribed by a second AI agent of ours that had not seen the
  folder's transcriptions; numbers only, one manuscript line per row.
