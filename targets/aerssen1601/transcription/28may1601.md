# Inv. 2019 (1601) - letter 12, Paris 28 May 1601 (scans 62, 63) - cipher passages with interlinear decipherment (fork trD)
Notation: CONVENTIONS.md (+UPDATE). Extra sign names used here:
- `d` = insular d (round body, ascender hooking left) = ra ; `8` = delta-like = la ; `d+` = d with cross on ascender = pa ;
  `alpha^` = barred alpha = lu ; `k^` = k struck through ascender = ri ; `K` = capital-K-like sign = mo ;
  `B` = heavy 8/B-like blob = f ; `schwa^` = barred Ə-like (reversed 9) = mi ; `inf` = ∞ ; `b+` = b with crossed ascender = ni ;
  `3'` = 3 with grave tick (code word).
- Bars between a gloss and the cipher line are sometimes ambiguous (gloss underline vs token bar): marked `^?`.
- SEG word for a code name = the name; gloss spelling kept, normalised in measure.
