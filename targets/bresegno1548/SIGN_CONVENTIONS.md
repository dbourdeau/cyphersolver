# Sign names for Bresegno 5 Oct 1548, c. 15r (shape names only, no values)

One token per sign, tokens separated by spaces, one output line per cipher line (L01-L24).
L01 starts after the clear words "lo q agora se offrece es que".

| name | shape |
|---|---|
| `o` | small oval with a horizontal stroke through it that sticks out on both sides (like -o-) |
| `O` | taller closed oval with the bar inside (like a theta), when clearly different from `o` |
| `d` | delta-like sign: round bowl with an ascender curling back to the left |
| `L` | the "ls" ligature: tall looped stroke joined to a long s-tail |
| `h` | h-like sign (write `hs` only if an h and an s-tail are clearly one joined sign; else `h s`) |
| `C` | large looped C, the loop rising above the line and the tail going below it |
| `#` | double cross: two upright strokes crossed by two bars |
| `+` | single cross |
| `T` | inverted T (a short upright on a base bar) |
| `q` | q whose descender is crossed by a bar |
| `a` | a with a long s-like tail below the line |
| `ms` | m with a long s-like tail |
| `D` | D-shaped sign |
| `s` `n` `x` `r` `i` `2` `3` `4` `5` `6` `7` | as written, when standing on the line as a full-size sign |
| `{bar}` etc. | groups that look like clear letters (bar, bir, bur, Ar, Per, Gra, Bran, mi ...): write the letters in braces |

Marks:
- superscript digit n above/after a sign: `o^5`; two digits: `o^24` (in reading order); digit below a sign: `o_2`
- dot under/over a sign: `x.`
- struck-through sign: `~o~`
- uncertain reading: append `?` (e.g. `d^3?`); unreadable sign: `[?]`
- a shape not in the table: give it a short new name and describe it once in a footnote

Ignore the small interlinear letters in a lighter brown ink (a contemporary decipherer's notes). Never transcribe them
and never let them influence a reading.
