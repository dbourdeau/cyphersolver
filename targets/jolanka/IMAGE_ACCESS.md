## The 112 other cards
Access mode "Authentication required". An ordinary DECODE account gets "Insufficient permissions to so see the full
image" and a 17,947-byte placeholder; the Image Manager link returns to the login page. Not worked around. Access is
the owner's or DECODE's to grant.
