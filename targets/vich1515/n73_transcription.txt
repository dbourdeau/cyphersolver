# SYMBOL LEGEND (label : glyph)
#  PHI  : two small loops side by side on a descending stem ending in a dot (phi / "ꝕ"-like); very frequent
#  RS   : 'r' joined to a long-s/ß hook with long descender ("rſ", "rß")
#  RH   : 'r' (x-like) with double oblique bar ("r#")
#  KH   : capital R/k-like letter with double bar ("R#", "k#")
#  TH   : 't' with double bar ("t#")
#  AH   : 'a' with double bar ("a#")
#  MH   : 'm' with bar/cross at end ("m+")
#  B8   : ß/8-like sign with descender (looks like "ȝ"/"g" on a stem)
#  N8   : 8/delta-like figure, loop below open hook above ("γ"/"8" standing alone, no stem)
#  Z    : standalone flat 'z' (2-like)
#  ZO   : large looping 'y/z' with small 'o' subscript at the end ("Ƶo")
#  ZH   : 'z' with p-like descender ("ʒp"/"zp")
#  GS   : 'g' followed by s-shaped tail ("gſ"), without the raised o (cf. word gso)
#  O    : small round o standing alone
#  OT   : o with trailing horizontal stroke ("o-", sigma-like)
#  X    : standalone x (often with a hooked lower-left tail)
#  CT   : 'c' + two short uprights under a bar ("cπ", "cii")
#  YH   : 'y' with horizontal bar through the descender
#  BO   : 'b' with raised o (often with over-bar) ("b°")
#  FH   : f/long-s with crossbar ("ƒ", "ŧ")
#  SL   : two parallel long slashes ("//")
#  LAM  : lambda/caret sign ("Λ")
#  DH   : d with crossed ascender ("đ")
#  EQ   : '=' with a vertical ("‡", "=|")
#  SUPNO: superscript "no" with a dot, written after PHI (probably a mark/nulla, kept as token)
#  QH   : looped q-like sign with cross (rare, line starts)
#  CD   : reversed-c / hook sign "ɔ-" (rare)
#  V    : small v/~ (rare)
#  rare singletons, uncertain: SS (long double s), LO, PH, OS, Q, PSI, D, CII, 7H
