# Sign names used in the transcription

The names are shape labels only. Values are in `key.tsv`.

| Name | Shape |
|---|---|
| `oo` | two small circles joined by a bar |
| `ou` | circle joined to a double-stemmed bar |
| `uo` | double-stemmed bar joined to a circle on its right |
| `u` | flat bar with two short stems |
| `1` | flat bar with one short stem (inverted T) |
| `U` | shallow box open at the top, three dots inside |
| `D` | three dots above a bar |
| `A` | capital lambda |
| `+A` | capital A with a long crossbar |
| `<` | less-than sign |
| `V` | inverted A with a crossbar |
| `3` | 3 with a tick on top |
| `3p` | plain 3, no tick |
| `Z#` | 2 run into a double stroke with one bar |
| `z` | 2 with an underbar and a dot |
| `Th` | circle on a horizontal bar |
| `+Th` | the same with a stroke crossing the bar on the left |
| `H2` | hash with two bars |
| `Hh` | double stroke with one bar |
| `H3` | triple stroke with one bar |
| `*` | six-armed asterisk |
| `K` | capital lambda with a tall cross through it |
| `X` | crossed-out circle |
| `Ls` | l-shaped loop with an S tail to the right |
| `Hs` | hook, no loop, with the same S tail |
| `S` | long s with a small circle at each end |
| `B` | b with a long hooked stem |
| `C` | open arch with a ball on top |
| `d` | round 6 with a short stem and a tick |
| `=O` | double dash into a circle |
| `P` | circle on a cross (Venus sign), one or two crossbars |
| `g` | crossed 9 |
| `9` | plain 9 with a tail, no cross |
| `O.` | circle with a central dot |
| `~` | S-hook lying on its side with a dot |
| `wv` | wavy line with a shallow dip |
| `+` | plain cross |
| `F` | flag: stem with two short bars to the right |
| `I:` | stroke followed by a colon |
| `E:` | capital E with a colon in it |
| `5 6 7 8 10 14 24` | numerals as written; 10 and 14 have the 1 as a plain stroke |
| `ii` | two dotted strokes (11) |
| `Ex` | epsilon and dotted x, read together |
| `Eo` | epsilon with a small o inside |
| `e` | epsilon alone |
| `n:` `m:` | Latin n or m with dots above |
| `d:` `q:` | tall d or q with a colon or dots |
| `Eb` | 6 or b with two crossbars through the stem |
| `Q3 Q4 Q6 Q7 Q8` | rho with a looped tail and a numeral above |
| `H9` | capital H with a 9 above |
| `Sicut Insuper Postq` | clear Latin words written among the signs |
