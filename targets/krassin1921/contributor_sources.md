# Sources

- US National Archives (NARA) RG 59, Central Decimal File 1910-29, 861.00 (Political Affairs, Russia), microfilm M316 roll 43 (861.00/8774-8910, NAID 604704577, https://catalog.archives.gov/id/604704577).
