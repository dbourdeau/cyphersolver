# Note de procédure P03 — extension (14/11/2026), écrite AVANT tout décodage
Base 158/159/161 : T2 (ef6f9c6c…) + gloses T2 (47231ba9…) + T3 aveugle (a5910b4c…) gelés. Séquences C : 2 (158-16-1, 159-02-3),
9 jetons F < 300. Les gloses de ces lettres sont pour la plupart pâles et ne couvrent qu'une partie des séquences (P).
Application de la clause d'extension du PREREG (ordre 167, 351, 254, 300, 299, pages entières, sur les seuls comptes) :
un sous-agent aveugle neuf (A2) fait passe signes (hachée) puis passe gloses sur les 5 pages ; le cumul C est calculé dans
l'ordre du PREREG. Si le cumul n'atteint pas 300 jetons F en C : NON MESURABLE, pas de T3 ni d'arbitrage (inutiles).
Si 300 est atteint : T3 aveugle + arbitrage par A2 sur les pages retenues, puis UNE mesure. Rien d'autre ne change.
