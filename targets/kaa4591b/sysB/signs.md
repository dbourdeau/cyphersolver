# Sign inventory, cipher system B (BayHStA KAA 4591 f.121-123, f.264)

Codes used in the sysB/*.tsv files. Signs within a word are separated by '.', words by space.
'?' after a code = uncertain reading. Letter values (from glosses) are in key_from_glosses.tsv.

| code | shape |
|---|---|
| O+ | circle with inscribed cross (⊕) |
| OD | circle with a central dot (⊙) |
| O | plain open circle / round o |
| X | plain saltire cross x, written small at x-height |
| AST | x with a short horizontal stroke through it (starred x, ⋇). In early notes also typed lowercase x; normalised to AST |
| HH | double-barred "#"-like sign: two or three short verticals crossed by a horizontal bar (ǂǂ, "ⅲ with bar") |
| 3 | "3"/ʒ-shaped sign with descender below the line |
| 9 | "9"/g-shaped sign with loop and descender (sometimes written as "gg" pairs, =9.9) |
| U2 | small "2"/"z" shaped sign with a tail, like a flattened 2 or "ʒ" at x-height (sometimes like "n" with a tick) |
| N | "n"-like hump sign; frequently followed by M-shape in "M.N" = the stroke group looking like "m/n" |
| M | "m"-like sign with tall ascender hook ("ﬁ"/ "tt-ascender"): three minims with a caret/loop above ("ᶆ") |
| W | "w"-like sign (double v) |
| D | "δ"/"∂"-shaped sign with tall looped ascender (like a reversed 6 / delta) |
| EQ | double horizontal wavy bar "≡/=" (long) |
| EQs | short "=" with a dot or mark above (≐ / ≟); distinct from EQ |
| Z | "ʒ"-like tall hook / "z" with descender (distinct from 3: flat top) |
| B | "6"/"b"-shaped sign with looped bowl |
| T | tall cross "†" (dagger, long vertical with crossbar) used inside words |
| DAG | stand-alone large dagger/cross with long descender (word sign) |
| FLW | four-lobed "flower" sign ✿ (word sign) |
| BIGX | large saltire X standing alone (word sign) |
| XH | small x with vertical stroke = "ⅹ-with-stem" |
| H | "h"-like sign with tall ascender |
| Q | "q"-like sign; always followed by U2 (qu) |
| V | "v"/"ʋ" cup-shaped sign |
| I | "I"-shaped tall sign with serifs |
| Y, K, XC | rare/uncertain shapes (Y fork-shaped; XC large X with loop, first word of R9323 l.3) |
| [clear:w] | uncoded word in plain Latin |
