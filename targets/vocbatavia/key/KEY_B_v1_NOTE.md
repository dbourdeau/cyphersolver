# KEY_B_v1: the second cipher system in the VOC letters of 1640 and 1643 (built 25 Nov 2026 UTC from glosses; key evidence, not a test)

Finding [derived from the glosses]: besides the homophonic number cipher of KEY_v2 ('system A', 1623-1643), the 1640 and 1643 letters use a
second, mixed system ('system B'): letters and numbers both stand for plain letters, and a number in system B does NOT have its KEY_v2 value
(e.g. 2 = n in A, t in B; 16 = p in A, n in B; 24 = w in A, e in B). Words in B are written as letter strings ('mrkmrkcbd' = Tartarien),
as number strings ('24 39 17 30 16 5 50 20' = eylanden; '2.12.16.16.24.16' = tonnen) or mixed ('m.12.16.d.24.20' = tonnen; 'crf: 21 d' = Japan).
Roman numerals are code words (XXI = silver, IV = gout). System B words are mostly names, places, goods and amounts.
How a reader of the time knew which system a number run used is not known: perhaps B runs are the ones joined with letters or set off with ':'.
This explains the KEY_v2 failures: 1643 runs 905.3 (eylanden) and 902.4 (tonnen) and the 1640 body runs (inv. 1134_0570) are system B.
KEY_v2 is unchanged. KEY_B_v1 is a new key, built only from glosses, with no held-out test yet.
