# Sign conventions (Van Malen letters, Gelders Archief 0372 inv. 52)

Written before any value was tried; shape names only. One capital code per sign. A space is a gap on the page.
Clear script is written in `<...>`. `?` = a sign too faint to read. `&` = a heavy looped sign (two places in
letter 1) that is not identified.

| code | shape |
|---|---|
| L | capital lambda |
| F | circle with a vertical stroke (phi) |
| U | omega with a central stem |
| W | pi-omega: w with a flat bar on top |
| Z | z with a long descending tail |
| D | o with a tall ascender (delta / Cyrillic be); often a small cross above it, not kept apart (see below) |
| O | plain small o |
| M | two o's joined (oo ligature) |
| N | four with a doubled crossbar (hash-four) |
| A | four with an arrow head (arrow-four) |
| G | gamma (r-shape) |
| T | tau (T with hooked foot) |
| V | nu with a flat bar on top |
| Q | open box (square) |
| P | capital pi |
| K | x with a vertical stroke (asterisk-x) |
| X | straight x |
| C | cursive, rounded x |
| I | short vertical stroke (iota) |
| E | eight-form (two stacked loops; written in several variants) |
| Y | small hook open to the right |
| R | small terminal hook with a longer tail |
| H | capital eta (H) |

Settled on the image:
- The small cross over D is not consistent: it appears over D in some words and not in the same word elsewhere.
  It is not recorded; D with and without it is one sign.
- Pass 1 of page 2 merged X and C, Y and R, and O and M (written OO). Pass 2 keeps them apart by shape. This was done
  after the first key hypothesis, so it is not a blind distinction (see NOTES.md).
- A superscript sign above the line with a caret (letter 1 L21, X) is an insertion and is written where it belongs.
- Numbers (60, 59, 68) are written as figures inside the cipher and are kept as clear script.
