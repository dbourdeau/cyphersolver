# Batch 7: King despatches, finishing interrupted frames (transcription only)

Source images: `sources/raw/king_m30_2026-11-10/`. Output: `batch7_spans.tsv`, using the same columns as batch2 (`frame, page, line, span_no, groups, interlinear, placement, note`). This batch was read from the images alone. No key or word list was built or used, and no other files under `output/` or `research/` were opened, apart from the permitted rows in batches 1, 3 and 4, read only to see which lines were already saved.

Conventions are those of batch 2. Clear text on a line is in `{}`. `?` marks a doubtful digit, with the alternative given in the note. `_` marks a digit hidden at the binding. `^` is the caret-like mark after a group. A row with an empty interlinear and the note `bare; follows <word>` is a group with nothing written above it. Lines are counted from the first code line on the page, and lines written wholly in clear are counted too. Lines that run across the two strip halves were joined by matching the overlapping group, so no group is entered twice.
