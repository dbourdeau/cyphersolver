# Batch 3: interlined code pages, NARA M30 roll 5 (Rufus King, London, 1798)

Output: `batch3_spans.tsv` (tab-separated: frame, page L/R, line, span_no, groups, interlinear, placement, note).

Conventions
- `^` after a group = the caret-like mark the pen wrote after it (342^, 605^, 422^ ...). `?` = doubtful digit, alternative in the note. `_` = digit hidden in the gutter.
- `{...}` in the groups column = words written in clear on the code line (no group).
- Two or more groups in one row = the clerk's word (or word plus rule) stands over all of them. `ambiguous` = the word only partly covers a neighbouring group or sits between two groups. Groups beyond the end of a word or rule are given their own rows with an empty interlinear, even where they probably belong to the same word.
- Line numbers count every written line of the page from the first code line, including lines wholly in clear.
- No key or word list was consulted. Two notes on frame 0101 point to a clearer recurrence of the same run of groups on frame 0134 as an aid to a doubtful first digit; the digits were not altered.

Status: frames 0101, 0119, 0134 done (see below). Remaining frames are listed at the end of this file and updated as work proceeds.
