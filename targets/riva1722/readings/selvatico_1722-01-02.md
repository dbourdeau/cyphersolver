# Selvatico Estense (Modena) to Giuseppe Riva (London), "2 Genaro" [1722], cc.2-3: reading

Conventions: text between asterisks is from cipher, the rest was written in clear. [181] = a code with no value; [?word] = a code value or word proposed from context, not read; a letter in brackets inside a word = supplied or emended (the unit is counted not read in units.tsv); [...] = groups not read; (?) = doubtful reading of the clear hand; [clear text not transcribed here] = clear passage left out. Word division, capitals, accents and doubled consonants are editorial (the cipher writes doubled consonants once or marks them with a stroke).
