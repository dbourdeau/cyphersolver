# Key R5018 — Charles VI / Windischgrätz 1720 cipher key (transcription)

Source: DECODE record 5018, image IMG_R5018_I28969_P.jpg (recto, the whole key on one large sheet).
IMG_R5018_I28970_P.jpg is the verso: blank except "N°" (pencil) + "81" (red crayon; or 31?) and a faint docket, bottom-left, written sideways: "Ziffern mit J[hr]: K[ayserlichen] M[ajestät]: / ... mit dem Grafen / [Windischgrätz?] ... / ...lia?" (only partly legible). No key content.

## Layout

One sheet. At the top a ruled grid, one column per letter A B C D E F G H I K L M N O P Q R S T V W X Y Z
(24 letters; no J, no U — I serves I/J, V serves U/V). Under each letter:
- row 1: a two-digit number (the scribe writes "1" as dotted "i"/"j", so "i8" = 18);
- row 2: a graphic sign;
- row 3 (vowels only): a second number — A 35, E 38, I 36, O 34, V 37.
So each letter has two (vowels three) homophones: number, sign, (extra number).
Letter numbers occupy 10–38; nomenclature numbers start at 40.

Below the grid: a nomenclature in ten narrow columns, alphabetical by headword (German/French/Latin words,
proper names), each entry "word ... code", codes being either numbers 40–209 or two-letter groups (e.g. "cu", "fg").
Some entries were added later in a different (paler/orange) ink, some with no code visible.
Bottom-right: "errantes 9.5.4.6. 3.7." = nulls (the single digits 3 4 5 6 7 9).

Glyph crops of each letter sign: key5018_glyphs/<Letter>_letter.png.

## Notes
- Codes are numbers 39–210 and two-letter groups. The groups are vowel-final (ba be bi bo bu, ca ce co cu, da de ... zu) or
  consonant pairs (ab ac ad af ag al am an ar as at aw; bc bd bf bg bh bl bm bn bp bq br bs; cb cd cf cg ci cl cm cn cp cr cs ct;
  db dc df dg dh dl dm dn dp dq dr ds dt; fb fc ff? fg fh fl fm fn fp fq fr fs ft; gc gd gf gh gl gm gn gp gq gr gs gt;
  hb hc hd hf hg hl hm hn hp hq hr hs ht; ib id ie je; lf lg lh lm ln lp; pr).
- Letter numbers (10–38) and nomenclature numbers (39–210) do not overlap; the single digits 3–7 and 9 are nulls.
- Entries marked "(later ink)" are in a paler brown/orange ink, added after the key was drawn up
  (Bassewitz, Brancas Cereste, Fleuri, Flemming, Fenelon, Jülich und Bergen, Mr Pointz, Rottemburg, R?wnſpery, Seckendorff,
  Wratislau, Windischgrätz, Walpole).
