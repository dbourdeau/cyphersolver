# Sign conventions, DCXXI.3.231.1 (Pedro Duhart to Vicente Gutiérrez, New York, 29 Aug 1921)

Written before any key was built or applied. Shapes only, no values.

- The cipher is typed on the same machine as the clear Spanish, in the same type: the signs are the 26 capital
  letters of the typewriter (Latin A-Z). Each sign is recorded as the capital it is.
- A cipher run is a stretch of capitals inside the lower-case Spanish text. Runs are numbered R01-R17 in page order.
- Word spaces inside a run are kept as typed (one space). A line break inside a run is written as one space.
- An apostrophe typed inside a run (R12) is kept.
- A lower-case `y` typed directly against a run (`yEPBSLN...`, `yOLURZ...`) is the Spanish word "y" in clear type
  and is not part of the run; it is noted, not transcribed into the run.
- A closing bracket `)` after R01 is clear punctuation, not part of the run.
- An overstruck letter (one capital typed over another) is transcribed as the letter that lies on top and is
  noted in the run's comment (R05, letter 8; R07, letter 3).
- Lower-case ordinals `2o 3o 4o` and `1o` (with underlined o) are clear text (ordinal numbers) and are not
  transcribed as cipher.
