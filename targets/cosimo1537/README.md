# Cosimo I de' Medici to Agnolo Niccolini, 1537 to 1539: the cipher passages

Cosimo I de' Medici, Duke of Florence, writes to his envoy Agnolo Niccolini. The letters run from December 1537 to August 1539. Their secret passages are in a number cipher with no spaces between the codes. Two systems occur.

Florence, Archivio Niccolini di Camugliano, Fondo antico 214, inserto 1. DECODE records R4033 to R4054.

| Records | System | How the folder decodes them |
| --- | --- | --- |
| R4034 to R4038 (December 1537 to March 1538) | the earlier system | from key: the archive's key table, DECODE record R4033, as I read it; code 29 = t from ciphertext |
| R4039, R4041 to R4050, R4052 to R4054 (October 1538 to August 1539) | the main system | from ciphertext: my own key, not checked against a key |
| R4040 | another system, with too few codes | not in this folder |
| R4051 | no cipher | not in this folder |

## The counts by the word rule

The rule of 19 November 2026 counts sure cipher words only. A word is sure here when every letter of it stands in the decode as a code with a value, with no doubtful digit (in the earlier system: no doubtful token), and nothing in it is supplied or marked.

- The decode has no word cuts, so the word cuts are those of my reading. A word of the reading is sure when each of its letters stands in the decode, at its aligned place, as a code with a value and no doubtful digit, and nothing in it is supplied.
- The holes are the words of the reading that are not sure, each bare mark `…` of the reading, and each stretch of the decode between two passages that no mark stands for. Each mark and each stretch counts as one word. Its extent is unknown.
- So the number of cipher words and the read share are estimates.
- A break `…` can stand for clear words, which the rule leaves out. The files do not show which breaks do. Each break counts as a hole, so the share is the lower of the two.
- The readings of R4034 to R4038 mark every letter and word that the key does not give, as their pages say. Each marked word is a hole, and so is each `…` and each `[...]`. Each `…` and each `[...]` counts as one word, extent unknown.
- A word on code 29 takes t from ciphertext. The counts give both cases: with 29 = t as a value of the key, and with every word on code 29 as a hole ("if 29 is a hole" below). Maintainers' note, 20 November 2026: the first is the count of record; a word on code 29 counts as given by the key (`NOTES.md`).
- A document with no reading: only the words that a word sign or a word code gives with no doubt are sure. Its number of cipher words and of holes is not known.
- The sure words of the main system come from my key from ciphertext. If a value of such a key does not count as given by the key, no word of the main system is sure.
- The floor for texts under 40 cipher words: each document with an estimate under 40 words has more than 2 holes, so the floor does not make it read. For a document with no reading, the floor cannot be judged.

## How to read the decode

Each record page ends with the decode, row by row. Each row gives the codes of the cut and the plain output of the key.

| Mark | Meaning |
| --- | --- |
| `abc` | letters of the key; the code for u and v is written u |
| `che` | the main system's word code 74 |
| `·` | a code to which the key gives no value |
| `⟨a⟩` | a code that holds a doubtful digit of my transcription; the key's value for the digits as read |
| `[?]` | a clear word, or a stretch of the row that does not read |
| `#` | a sign of the row that is not a digit |
| `{word}` | earlier system: a word sign of the archive's table; `{A \| B}` where my two readings of the table differ |
| `[nn]` | earlier system: a code that the key does not hold; a bar over the digits marks a barred code |
| `&` | earlier system: the table's sign & (et) |
| `°` | earlier system: a doubtful token (a doubtful digit, or a cut that the table does not force); the reasons follow the row |
| `…` | earlier system: clear words, a stretch that does not read, or raised writing that cuts the row |

In the earlier system, code 29 is decoded t, from ciphertext. In the codes line, `~` follows a code with a doubtful digit, `|` is a visible space of the row, `.` a point and `[?]` a break. The earlier codes line uses `°` for a doubtful token and `/` for a break.


## What the letters say

Each record page gives a summary, and where one stands, a reading in Italian and in English.

- **The earlier system (from key):** the papal tithes on Florence, December 1537 to March 1538 (R4034 to R4038). Cosimo was given to understand that he should proceed as "the prince … Doria" and the city of Genoa proceed (R4037). Niccolini is to accept the extension "se[c]ondo Clemente" (R4038).
- **4 October 1538 (R4039):** a marriage alliance and "the matter of the wife".
- **18 January 1539 (R4047):** a papal "motu proprio".
- **11 August 1539 (R4054):** the arrest of Biagio della Campana. The passage names Giulio, the natural son of Duke Alessandro.
- The other letters of the main system show short pieces only.
