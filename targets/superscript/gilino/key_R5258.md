## MATCH: R5258 = Carteggio Sforzesco cart. 1591 no. 24 (1 image, IMG_R5258_I30211_P.pdf)

Docket in the lower middle of the sheet: **"Cum equite Bilie / extracta ex cifris"** ("with the Cavaliere Bilia,
extracted from the ciphers"). So this is a key reconstructed (or copied out) from that correspondent's letters, not a
clean issued key. It is messy: many homophones, struck-out entries, entries added in a second ink.
Companion: **R5237** (cart. 1591 no. 3), docket "Cum Egr[egi]o Bilia" / pencil "Cum equite Bilia": a plain
numeric alphabet (A..&9 = 12,13,14,18-24,28-34,38-40,10,11); a different, simpler key for the same man.
The nomenclator of R5287 (cart. 1591 no. 53, dated 7 Nov 1525 in the header) lists "Cavallero billia" A28 and
"Ghilino" A29 as two different people, so "Bilia" vs "Gilino" needs checking against the R8572 signature.

Base glyph "G" on the key (barred, number above) = the r8572 "6". The r8572 "d.nn" behaves like "D.nn".
