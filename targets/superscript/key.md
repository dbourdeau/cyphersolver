# Worcester (Ghinucci) superscript cipher: key as recovered (working file)

## System (established 9 Oct 2026 from R8589 + L&P iv 5282 and R8590 interlinear)
- Syllabic substitution. A base glyph stands for a consonant "row"; a superscript digit picks the syllable
  in that row (consonant+vowel). The digit-to-vowel assignment differs from row to row and has homophones.
- A base glyph WITHOUT superscript is a single letter (and is not the row's consonant: bare o = p, bare z = t, bare x = a ...).
- Nulls are frequent (often with two-digit superscripts 12-19, or any glyph). In the deciphered letters
  (R8589, R8590) the decipherer struck nulls through with a light diagonal pen stroke.
- Code signs: a long horizontal squiggle "mm" with a superscript (mm9 = orator Pontificis in R8589); ñ2 = Cæsar.
- No word division.

## Glyph names used in the transcriptions
1 = the "1"/long-s glyph (s-row); Q = open square; F = phi; P = pi; T = theta; Y = psi; E = epsilon;
O = circle with dot; # = hash; & = sigma-t (et); D = p-like "ꝺ"; R = "ro" ligature; W = "tw" glyph;
mm = long squiggle code sign; [ = open bracket "⊏"; V = horizontal "‒v‒"; Z = barred z; z = plain z;
other letters as they look (K, L, o, d, x, y, f, a, q, z, c, e, n, r, u, h, b, g, p, v ...). Superscripts follow
the glyph as digits: K9, L3, mm16. "!" after a token = struck by the decipherer (null).
