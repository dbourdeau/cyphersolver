## Pass 5 (f.168v cut at fixed pitch, tok/g168v_*; aligned to f.172 paragraph 2)
- line 0: clear "el exercito por estas partes /" then `3 an Jap` = al papa; clear "a estos suyos les paren"
- line 1: `d boe ꝺ | ꝑo α ram | beq | nub | nf ꝺ [u] ...` = ha-ve-r u-sa-do de una gran p-r-u-dencia: so here the
  p-loop `ꝑo` stands before `α ram` where the clear has *usa-*: either `ꝑo` = *s* and `d` (hooked) = *u* after
  *haver* as a code group, or the p-loop has a second value. Not settled.
- line 1 end / line 2: `sad ꝺ α | rad | mus ꝑo` = queda-r-a **sobre** las (spaldas): `rad` = *sobre* here,
  which conflicts with `cad` = sobre from f.171 L0 unless the two are the same group misread. If `rad` = sobre,
  the target's opening `mus ꝑo rad ꝑo vo ꝑo` is *las* + sobre + … — a code group for *letras* (or similar) is
  likelier, so `rad`/`cad` need a 5x comparison.
- line 2: `dim | hag | 3 il rac do | gap | cut | mus nom | ka | ...` = se / por que a-go-ra di-ze que toda la
  guerra le …: `3il` = *ago-*? `rac` = *di-*? `do` = *ze*? (tentative; `do` = n elsewhere).
- lines 3–9: `boe ꝺ ꝑo α ram suf α ... dim lex ... kah gib sof rol ... ma pur ... lex ttt α do ꝑo= sof ꝑo= Ɉ ꝑo= g 3 ttt Є ott α ꝺ` = haver usado de la … / no se ha havido mas provission de dineros … he scrito / no canso de sollicitar.

## Pass 7 (duplicate f.130 tiles, crops/cmp_d130L*.png; target L5 tiles cmp_L5)
- `d` (hooked, at the head of a stretch) = **ha**: f.168v `d b oe ꝺ` = ha-v-e-r; f.128 L5 `[f~ d] b la g` = ha-b-l-é.
- `b` (plain latin b) is a letter, **v/b** (and *h*? see below); `oe` = **e**, `o3` = **a** (or *o*): they are
  separate tokens, so the "groups" `boe`, `bo3` of passes 1–5 were wrong.
- `3` (three-shape) = **r** in *a-v-e-r al-g-o* (`α b oe 3 an # 4`), as in *na-r-izes*; the six-like `ꝺ` is
  also r (*o-r-a*) or s? (*de-s-e-a*): the two need a final check.
- `x` = **e** or **en**: `nf 4 do x` = po-n-e(n).
- f.128 line 1 reads: `ꝑo Jim nf g ttt b o3 do | gap sof ꝺ x α | b oe 3 an # 4 | gap ꝺ 3 oo Є x ꝺ o` =
  *s-os-p-e-c-h-a-n / que de-s-e-a a-v-e-r al-g-o / que r-r-?-i-e-r-o…* → **"que le ponen sospecha que desea
  aver algo que …"** (`b` = h in *sospecha*, v in *aver*: one sign for the two aspirates, or two look-alikes).
