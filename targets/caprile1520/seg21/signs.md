# Caprile 1520-21 graphic-sign cipher: sign inventory

Labels used in `../caprile1521_transcription.txt`. Example files are line-piece crops in this folder
(`<SRC>_Lnn_k.png`, 2x upscaled, k = piece left to right); the example column names the piece where a clear
instance sits and its neighbours, so the sign can be found by eye. Individual per-sign crops were not cut.
Sources: R1139 (6 Apr 1521), R1138 (16 Feb 1521), V1920 (v1920_3.jpg), V1921 (v1921_2.jpg), R1136 (8 Mar 1520).
