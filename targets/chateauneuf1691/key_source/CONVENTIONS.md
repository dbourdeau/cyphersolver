# Transcription conventions (AN AE/B/I/381, Châteauneuf 1691-1694) — numeric code
Images: Archives nationales, AE/B/I/381 (private reproduction, 51 JPEG; not distributed). Transcribers worked on local crops.
Images are PRIVATE: never copy them anywhere else, never upload.

Output format (plain UTF-8 text), one line per manuscript line that contains cipher numbers:
  IMG|SIDE|LINE|numbers
  - IMG = 4-digit image number, SIDE = L or R (left/right page of the spread; S for single page), LINE = running line number of the cipher line on that page side (1,2,3... counting only lines that contain cipher).
  - numbers separated by single spaces, exactly as written (the scribe separates groups with dots or dashes).
  - Doubtful digit: give your best reading followed by ? (e.g. 128?). Two possible readings: [128/138]. Illegible: ###.
  - A mark over/under a number (bar, dot, underline, apostrophe) : append ^ and describe once in notes (e.g. 45^).
  - Clear words inside the cipher run: write them in braces in the position they occur, e.g. 355 158 {de France d'Angleterre} 22 17
  - A group that runs across the line end: keep it on the line where it ends and note it.
Also write a short NOTES section at the end: which pages carry cipher, anything unusual (struck-out groups, corrections, numbers above 400, marginal notes).
