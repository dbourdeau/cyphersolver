# Conventions de nommage retenues (formes seulement) :
#   d   = petite boucle precedee d'un long trait oblique venant du haut a gauche ("\o").
#   dd  = deux petites boucles fermees accolees, sans queue (forme "oo" / infini).
#   +o  = croix droite simple suivie d'une petite boucle sur la ligne ; N13 = meme chose a haste haute recourbee vers le haut-droite.
#   4o vs N17 : haste qui descend nettement sous la ligne (avec barre) = 4o, meme si l'anneau touche ; haste courte, anneau colle,
#     long trait oblique venant du bas-gauche = N17. Frontiere incertaine (voir doutes).
#   8 vs N15 : 8 a boucle superieure fermee / barre plate = 8 ; boucle superieure ouverte avec crochet ou trait qui la traverse = N15.
#   n  = forme m/n a arceaux, derniere jambe libre (souvent avec amorce a gauche).
#   12, 13 = chiffre 1 avec marque haute 2 / 3 ; xo, x3, mx2, mx3, 3o, 4o, 5o, 6o selon SIGNS.md.
#   '.' seulement pour des points nets sur la ligne ; '.?' point faible ; petites taches ignorees ; ',' tel qu'ecrit (7r L19).
# Formes t ajoutees (forme seulement) :
#   t1  = petite boucle fermee isolee a hauteur de ligne avec une courte amorce (tique) en haut a gauche ; pas de long trait (pas d).
#   t2  = courbe en c inverse (ouverte a gauche) dont le bas finit en crochet a gauche, enchainee a une petite boucle a droite ("ɔo").
#   t3  = petite boucle fermee accolee a gauche d'un x (ou d'une croix oblique) ("ox").

#   t5  = petit crochet a hauteur de ligne + petite boucle a droite, dont le trait descend loin vers le bas-gauche et finit en crochet ("yo").
#   t6  = grand cercle ouvert enveloppant une petite boucle en forme de 2 (comme un 2 entoure) ; pas de longue queue descendante.

#   t8  = haste courbe (c ouvert) coupee d'un trait qui se prolonge en boucle a droite, la haste descend et finit en crochet a gauche ("ty" / "6x").
#   t9  = petite boucle fermee isolee (comme t1/N4) surmontee d'un point.
#   t10 = alpha (a) surmonte d'un point, epaissi a gauche (6v L21).
#   t11 = deux traits horizontaux courts superposes ("="), le superieur un peu crochu (6v L24).
#   t12 = MARQUE HAUTE : petit trait vertical court sureleve a droite (apostrophe) (jeton 4t12, 6v L24).
#   t13 = forme n (deux arceaux) dont la derniere jambe se ferme en petite boucle en haut a droite ("np").
#   t14 = haltere O surmonte d'un point au-dessus de la barre.
#   t16 = haste avec barre superieure recourbee vers le haut-droite et petit crochet a gauche, boucle a droite a mi-hauteur,
#         longue descendante finissant en crochet a gauche (7r L10).
#   t17 = croix a haste haute recourbee (comme N13) enchainee a droite a un alpha (boucle a queue) ("ta") (7r L12).
#   t18 = croix dont la haste porte en haut une petite boucle fermee triangulaire (4 pose sur une croix), suivie d'une petite boucle sur la ligne (7r L24).
#   t20 = d (boucle a long trait oblique) surmonte d'un point (7v L09).
#   t21 = dd (deux boucles accolees) surmonte d'un point (7v L18).
#   t22 = x surmonte d'un point (8r L08).
#   (t15, t19 : numeros non utilises.)  t? = signe illisible ; t?_ = signe tache/barre (pate d'encre + trait oblique).
