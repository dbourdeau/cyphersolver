# coloma1622 - comparison with a Spanish nomenclator of 1615 (Real Biblioteca, II/1850, f. 20)

Status: comparison only (Brice Dudout, 18 Nov 2026; entries of the table withdrawn 19 Nov 2026). The 1615 table is **not** the
key of the Lyon letter, nothing points to a sister table, and it gives no value for any unresolved code. Nothing in `key.tsv`,
`reading.md` or the counts changes.

## Source

Madrid, Real Biblioteca de Palacio (Patrimonio Nacional), **II/1850, f. 20**: a Spanish nomenclator that the library dates to 1615
(Gondomar papers). An image was sent to Brice Dudout on 16 Nov 2026 by a researcher at the Real Biblioteca.

**The table belongs to the Real Biblioteca.** Neither its image nor its entries are in this repository: the publication permit we
hold (Patrimonio Nacional, file RB102/26) covers the Europe chiffrée site only, and the library's own work on these ciphers is in
progress. Only counts are given below. The table can be consulted at the Real Biblioteca, Madrid, under the shelfmark
**II/1850, f. 20** (catalogue: https://realbiblioteca.patrimonionacional.es/; the catalogue asks for a browser check, so no record
link is given here). Our working transcription of the table (one pass, 374 word entries, the alphabet and the syllable grid) is
not published.

## Method

Only values of the 1622 system that a contemporary clear supports are compared (key C04 plus the values read on the clears of
MSS/18428 on 13 Nov 2026): 40 code words and 45 letter and syllable signs. Values placed by the sense (for instance _60_ CASA,
138 empresa, 139 efecto) are left out. The script compares signs, code numbers and, for word order, the pairs of common words
with the same initial (a global rank correlation proves nothing, since both lists are alphabetical).

## Results

| test | result |
|---|---|
| letter and syllable signs present in both tables | 45; **1** with the same value |
| code words of 1622 held by a clear | 40; **1** with the same word at the same number (in the D-E stretch, an effect of alphabetical order) |
| order of common words with the same initial | 22 pairs in the same order, 19 reversed (indicative: few words, pairs not independent) |

- Vowels are series of numbers in both tables, but the series are not the same.
- The syllable grids differ, and some 30 groups that are syllables in 1622 are code words in 1615.
- The one shared code word is an effect of alphabetical order: both lists are alphabetical.
  Elsewhere the numbers of common words differ.
- Nothing in the 1615 table allows a value to be carried over to an unresolved code of the letter (code 2 included).

## The "cifra general" of 1620

Same check against the cifra general of 1620 reconstructed and published in *Avisos* 28 (98), 2022 ("Criptoanálisis de una carta
en cifra del conde de Oñate al archiduque Alberto y reconstrucción del nomenclátor"): its syllable groups look more like those of
the letter (fan, fen, san, sen, car ...), but none of 13 groups compared has the same value, and none of 17 code words compared has
the same number (negocio 136, underlined 60 guerra in 1620; 309 and 252 in 1622). A lead only, nothing carried into the reading:
zan = que in 1620, while the group "z cer zan" of the letter (1v.21) stays unresolved.

## Conclusion

Same family of Spanish nomenclators (number series for vowels, a syllable grid, an alphabetical word list, underlined or marked
numbers, nulls), different tables. The key of the Lyon letter is still known only from the contemporary clears of Feria's letters
and of MSS/18428.
