# Inventaire des signes — système S (alphabet de signes), Add MS 32657, 1585

Étiquettes ASCII fixées pendant l'apprentissage (R4689, R4835, R4836). Une étiquette par forme vue.
Les formes sont décrites en mots, aucune image ni dérivé d'image.

| étiquette | forme (description) |
|---|---|
| EQ | deux traits horizontaux superposés « = » |
| MP | croix à deux barres, comme « ∓ » ou « ≠ » couché : trait vertical coupé par deux traits horizontaux |
| HASH | dièse « # » (deux verticales, deux horizontales) |
| DIV | trait horizontal avec un point au-dessus et/ou au-dessous « ÷ » |
| TD | trait horizontal suivi d'un point « –. » (trait-point) |
| UT | T renversé « ⊥ » |
| BAR | une seule barre verticale « | » |
| N2 | deux barres verticales « || » |
| L | boucle haute comme un « l » bouclé (ℓ) |
| E | signe courbe en « e » ou « ɕ » (boucle ouverte, parfois avec queue) |
| FOUR | signe en « 4 » ou « φ » |
| SEVEN | signe en « 7 » |
| PLUS | croix « + » |
| W | « ω » (w arrondi) |
| WB | « ω » barré au-dessus (ϖ) |
| b | forme de « b » minuscule |
| c | forme de « c » minuscule |
| d | forme de « d » minuscule |
| f | forme de « f » long minuscule |
| g | forme de « g » minuscule |
| h | forme de « h » minuscule (ou δ) |
| i | forme de « i » minuscule |
| r | forme de « r » minuscule |
| m | forme de « m » minuscule |
| u | forme de « u » minuscule |
| K | forme de « k » / « R » majuscule |
| NUL | carré □, carré pointé ⊡, carré barré ⊠, triangle Δ : marqueurs, traités comme nulles |
| . | point isolé (nulle) |
| ? | signe illisible |

Séparateur de mots : espace. Mot en signes = suite d'étiquettes séparées par des espaces, entre crochets.
