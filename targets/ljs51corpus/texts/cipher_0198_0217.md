- Where: f. 102v l.11-12 (image 0209); f. 102v l.13-13 (image 0209); f. 103r l.1-2 (image 0210)
- Signs: 73 (chain record (by-eye count on the master))
- Earlier chain record, signs per line (102v.11): 38, 35; word groups written as Arabic words; the spaces do not keep the word boundaries (e.g. اتمدكل = دامت + لك)
- Sign inventory (102v.11): ordinary Arabic letters: a transposition (maqlub) of each word, not a substitution
- Cipher as written: اتمدكل لعامنا اعهبس بيتقوام ردط لجا دالحبر فا / ان نم ذا اكترذ نقهبام قصر لمنازا صفقولهر دا
- Rule: Each plaintext word is written with its even-position letters first, in order (2nd, 4th, ...), then its odd-position letters in reverse order (... 3rd, 1st). E.g. دامت (d1 a2 m3 t4) -> ا ت م د = اتمد; لك -> كل; النعما (hamza dropped) -> ل ع ا + م ن ا = لعامنا; سابغة -> ا غ + ة ب س = اعهبس; وبقيت -> ب ي + ت ق و = بيتقو; ما -> ام; طرد -> ردط; الدجى -> لج + ى د ا (ى written ا) = لجادا; الفجر -> لج + ر ف ا = لجرفا (written لحبر فا, with one extra tooth); يا -> اى; من -> نم; اذا -> ذاا; ذكرت -> كترذ; مناقبه -> نقه + بام = نقهبام; رقص -> قصر; الزمان -> لمن + ازا = لمنازا; وصفق -> صق + فو = صقفو (written صفقو); الدهر -> له + ردا = لهردا. The words are then run together and re-spaced arbitrarily, so it looks like a substitution text.
- Comparison with the clear copy: fits: 73 cipher letters vs 72 (as the cipher has it, 37 + 35; the page's plaintext has 70 + hamza). The cipher's form differs from the written plaintext in one word: the cipher has ما after وبقيت (بيتقو + ام: وبقيت ما طرد), which the page omits (وبقيت طرد); the hamza of النعماء is not enciphered; one extra tooth in لحبر (copying slip). Second hemistich letter for letter.
