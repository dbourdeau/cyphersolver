# Glyph legend (shapes only)

Use one token per sign, separated by spaces. Tokens:

| token | shape |
|---|---|
| V | downward-pointing triangle (like ∇), plain |
| Vt | same triangle with a vertical stroke rising from it |
| D | upward triangle (Δ), plain |
| D+ | upward triangle with a cross or tail below it |
| Y | psi/trident (ψ) |
| Y+ | psi with a cross below |
| Px | x joined to p (ꝑ-like) |
| W | ϖ / w-like sign with a long top bar |
| M | m-hump followed by a z-like tail descending (mʒ) |
| y3 | z-like/yogh tail without the m-hump (ʒ) |
| o | round o / zero |
| 6s | o with a cross above it |
| 6p | o with a plain upward ascender |
| # | double-barred cross (#, ‡‡) |
| #\| | # with a long vertical stroke |
| 1 | vertical stroke / digit one |
| 1. | one followed by a dot |
| T | inverted T (⊥) |
| + | plus/cross |
| Q | square box (□) |
| f | f/long-s with a crossbar (ƒ, ≠-like) |
| 3 | digit three |
| 4 | digit four |
| 2 | Z-shaped sign / digit two |
| z | z |
| c | c-shape |
| R | r with a bar and a tail (Ꝛ) |
| a | plain round a |
| al | alpha-like a with a tail (α) |
| pi | π-like sign |
| h | h with a descending tail (ɧ) |
| % | division sign (÷) |
| & | c/ç-like hook with a descender |
| xi | ξ-like sign |
| ? | cannot tell |

Use a new token name of your own if a sign matches none of these, and describe it.
