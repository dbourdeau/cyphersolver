## Conventions used in this file
- Table labels (Domnina key_1 / Lasry key_2): letters lowercase `<e> <i> <r>`; syllables `<to> <ce> <mi>`; words `<NON> <CON> <ET> <VENEZIANI>`.
- Homophone variants of a table letter: `<a>` = the "2" form, `<a'>` = the small plain circle form (Domnina's A has both); `<r>` = inverted T, `<r'>` = the b-with-top-bar form;
  `<o>` = the "oo/curly" form of key_2 'o', `<o'>` = the bold A form (key_2 'o' second), `<o''>` = gamma-like form (key_1 'O' first form).
- `<x/y>` = unsure between two table signs. `<?>` = illegible. `<@NN>` = a shape I could not match to the table (described below).
- Further variant labels: `<s>` = F-shaped S (key_1 S first), `<s2>` = g/z-shaped S (second), `<s3>` = I-form with bars, `<s4>` = bold N/M-form (fourth).
  `<r'/ri>` = the b-with-top-bar / '5'-shaped sign (key_2 r second form and 'ri' look identical in this hand). `<pe/de>` = a cluster of 3-4 loops without stem.
  `<ma/b>` = diamond with dots (key_2 'ma', key_1 B second form). `<n/ne>` = stem + loop + dots + bar.
- `<me/fa>` = bar on the left then a double loop (key_1 'me' short bar / 'fa' long bar are not distinguishable in the hand). `<du/do>` = plain triangle.
- Clear numerals stay as seen (`4m`, `2m`). Clear words are copied as written, `^x` = superscript, `?` doubtful.
