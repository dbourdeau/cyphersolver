# Supporting evidence for the partial decipherment of I 242,29

**Cyphersolver catalogue:** #1988  
**Researcher:** Alberto Garvía García  
**Manuscript:** I 242,29, 20 May 1610  
**Status:** Partial decipherment

## Purpose

This document accompanies the published partial decipherment of Philip III's letter to the Count of Añover.

It identifies the supporting manuscript evidence, distinguishes established readings from unresolved code groups, and provides references for further verification.

## Related manuscripts

The investigation also examined contemporary ciphered correspondence from the same archival series, including:

- **I 242,35**
- **I 242,59**
- **I 242,60**

The original manuscript PDFs for these three documents have been uploaded to [GitHub issue #499](https://github.com/dbourdeau/cyphersolver/issues/499).

Additional parallel evidence is discussed in the existing research files and issue comments.

## Independent verification

Brice Dudout independently transcribed and aligned material from I 243,18. His alignment provides additional evidence for the reconstructed cipher system, while some individual code groups remain unresolved.

## Remaining uncertainties

The published reading retains several provisional or unresolved code groups, including:

- `U01`
- `101`
- `114`
- `241`
- `e`

These should not be treated as definitively deciphered without additional manuscript evidence.

## Publication status

The letter has been published as a partial decipherment. The overall message is intelligible, but the reconstruction of the nomenclator remains incomplete.

This supporting document does not supersede the existing transcription, key, reading, translation, or validation files.
