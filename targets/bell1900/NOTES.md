# Bell to Mabel Hubbard Bell, 1900, "Unicode" code telegram (catalogue 763)

Status: read with a known key; written up (docs/bell1900.html); profile.json valid

Library of Congress, Alexander Graham Bell Family Papers, magbell.04100117. 27 Aug 1900, aboard a steamer.
Six code words and a name, checked on the LoC image: Roboro, Diallage, Siquando, Adalligo, Signinus, Promulgo, Bert.
(The By the People transcription has 'Signinas' as a signature; the image shows Signinus is a corrected word in the
middle, written under a struck-out Sigma.)

## System
Commercial phrase code: "Unicode" Universal Telegraphic Phrase-Book (1886 on). Each Latin cypher word stands for a
stock phrase. Key = the printed code book (public), so the method is known key applied.

## Reading
Method: known key applied (the printed code book). See reading.md and key.tsv. All six words were found on the
1896 page images (pp. 5, 35, 78, 88, 95, 96) and the phrases give a coherent telegram: "Telegram received. Glad to
hear from you. Wrote to you by this morning's post. Am quite well, and writing by post. Weather very fine, sea quite
smooth. [Put me £1,000 to win on —] Bert." Six of six code words read (100% of code tokens; Bert is clear text).

## Remaining gaps
- Promulgo reads as a betting phrase, which the letter does not explain. The printed value is certain on the page image
  (1896 ed., p. 78); only why Bell sent it is open. No outside blocker; no other edition is online (below).
- Bert: left as clear text; not checked against other letters.

## Editions
- 1896 edition (archive.org UnicodeUniversalTelegraphicPhraseBook): all six words checked on the page images, pp. 5, 35,
  78, 88, 95, 96. This is the reading's basis.
- 1889 edition (archive.org unicodeuniversa00unkngoog): checked in the OCR text layer only, not on page images. All six
  words are in it (Roboro printed as "Eoboro" and Signinus as "Signiniis" by the OCR). Roboro and Diallage sit on the same
  line as their phrase; Adalligo, Siquando, Promulgo and Signinus were located but not paired with a phrase in that scan.
- 1898 edition: not checked (no copy found; archive.org search on 30 Oct 2026 lists only the 1889 and 1896 scans). The
  catalogue note named 1889 or 1898. A different value for Promulgo there is the one check still worth making.
