# Sign conventions, catalogue 2192 (AGI Indiferente 737 N.171)

Shape names only; no values. One token per sign, tokens separated by a space, cipher word gaps written ` | `.
Line breaks of the manuscript are kept; each line starts with `<image>.<line>:`.

## Base shapes

| token | shape |
|---|---|
| `B` | b-like sign with a looped ascender |
| `L` | l with a cross-bar through the ascender |
| `Lh` | the crossed l joined to a hooked descender tail (written as one stroke group) |
| `nh` | an n-shape ending in the same hooked descender tail |
| `N` | open loop with a short upright stroke on its right (like a reversed sigma) |
| `D` | delta-like d with the ascender bent back to the left |
| `k` | small looped sign like a lying x / r rotunda, usually written before `B` |
| `x` | x-shape with a long descender |
| `co` | c joined to a small omega loop (one sign) |
| `w` | free-standing omega (two small loops) |
| `c` `q` `m` `n` `s` `g` `u` `r` `o` `a` `e` `y` `i` | signs shaped like these Latin letters |
| `1` | upright stroke with a flag at the top (like a numeral 1) |
| `3` | 3/z shape with a descender |
| `4` `7` | numeral-like shapes |
| `p` | p with a looped descender |
| `z` | flat z / zeta with a descender tail |

## Marks attached to a sign

| mark | meaning (shape only) |
|---|---|
| `'` after a token | one dot above the sign |
| `,` after a token | one dot below the sign |
| `"` after a token | two dots above the sign |
| `^` after a token | short stroke or tilde above the sign |

## Other

- `.` a free dot on the line between two signs (counted as a token).
- `/` and `//` the writer's slash marks at the end of a sentence or paragraph.
- `?` a sign I could not identify; `??` several.
- `+` the cross at the head of a paragraph.
