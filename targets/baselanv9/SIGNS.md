# SIGNS: baselANV9 neutral sign labels

Labels name the SHAPE, never a reading. Written while transcribing ff. 4r-4v (24 Nov 2026, Brisbane, before any key
building). A sign is one written glyph; marks written on or next to it are separate modifier labels, appended to
the base label without a space in the transcription (e.g. `Bx^`), and split off by the scripts.

## Base signs
| label | shape |
|---|---|
| `1` | short upright stroke with a small head (like ı) |
| `2` | two-shape |
| `3` | three-shape, sometimes with a descending tail |
| `4` | four-shape |
| `5` | open five-shape |
| `5b` | five-shape with a flat bar on top (like Ꞩ) |
| `6` | six-shape with a round head |
| `6s` | six-shape carrying a closed figure-eight loop on top (an 8 standing on a 6) |
| `6L` | six-shape with a single open loop rising to the right of its head |
| `6v` | six-shape with a straight upright stem (like б) |
| `6t` | six-shape with a short stroke rising from its head (like ϭ) |
| `6r` | six-shape with a long stroke sweeping up to the right, often crossing the next sign |
| `7` | seven-shape |
| `8` | eight-shape |
| `9` | nine-shape |
| `Am` | dollar-like sign (S-curve with a vertical stroke) |
| `Ab` | a-like bowl with a horizontal bar running out to the right |
| `Ar` | right-pointing arrow |
| `As` | a-like bowl crossed by a diagonal stroke descending to the lower left |
| `Bl` | solid ink blob |
| `Bx` | box: two uprights between a top and a bottom bar (like Π with a foot bar); an inner dot, often present, is not recorded |
| `Cd` | circle with a centre dot |
| `Cl` | colon (two dots one above the other) |
| `Cs` | circle with an inner spiral |
| `D1` | single dot on the line |
| `D2` | two dots side by side on the line |
| `D3` | three dots in a small triangle |
| `Dh` | delta-shape preceded by a small hooked lead-in stroke |
| `Dl` | delta-shape (round bowl, ascender curving back to the left) |
| `Ds` | dash (short or long) |
| `Dv` | dash with a dot above and a dot below (like ÷) |
| `Ea` | reversed-e / yogh-like shape with a tail running down to the right (ɘ, ʒ) |
| `Hk` | upright with a hooked bowl to its right (like ʖ or Ꮒ) |
| `Lb` | L-shape: upright with a foot to the right |
| `Lm` | lambda-shape (ʌ); a small dot inside the angle, often present, is not recorded |
| `Lmt` | lambda-shape crossed by an upright stroke |
| `Lr` | reversed L: upright with a foot to the left (⅃) |
| `Oc` | open circle |
| `Oe` | oe-ligature shape (œ) |
| `Oei` | oe-ligature shape with a dot inside its first bowl |
| `Pe` | two-shape joined to an e-like loop (ꝛe) |
| `Ph` | upright oval crossed by a vertical stem (like ɸ) |
| `Pl` | plus |
| `Q3` | small three-shape written below the line after the preceding sign |
| `Rt` | root-sign (√), alone or joined to a preceding six-shape |
| `Tk` | tack: dash with an upright at its right end (⊣) |
| `X` | x-shape, with or without a dot in the crossing (the dot is not reliably visible, so it is not recorded) |
| `Xc` | x-shape crossed by an extra stroke (often a stroke coming from the sign before) |
| `Yy` | y-like sign with a long descender (f. 159r) |
| `Sz` | sharp-s-like sign (ß) (f. 159r) |
| `Ec` | loop crossed by an upright and a bar, like an ampersand (f. 159r, end of a paragraph) |
| `?` | sign not identified (on f. 34r pentacle 4: a bold barred 4-like sign, possibly a planet sign) |

## Modifiers (appended to the sign they are written on)
| label | mark |
|---|---|
| `^` | dot above the sign |
| `_` | dot below the sign |
| `"` | two dots above the sign (diaeresis) |
| `~` | bar or arc above the sign |
| `@` | large loop: the sign's stroke runs on into a big loop above or around it |
| `^m` | a small m-shape written above the sign |

## No value
| label | what |
|---|---|
| `Fill` | long dash or double comma after a word (line filler, end of sentence) |
| `Eq` | double bar (=) or dash at a line end, or a double bar between words |

Labels added while transcribing the held-out leaves (ff. 15r, 159r, 34r), before any key building: `Yy`, `Sz`, `Ec`.

Separators in the transcription: ` / ` between words, a space between signs. A word broken at a line end with no
mark is left as two words on two lines; the alignment joins them.
