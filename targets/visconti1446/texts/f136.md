# BnF italien 1583 f. 136 -- Filippo Maria Visconti to Francesco Sforza, Milan 29 Nov 1446 (cipher slip)

DECODE R7907, one image. Key R5323 (also DECODE R1857 image 17).

**Transcription in use: `f136_transcription.tsv`**, the parallel session's pass of 29 Oct 2026 (see
`../peer/WORKLOG.md`): one row per sign with its key value and a note on its shape and its alignment with the
19th-century copy in BnF ital. 1597 f. 154, canvas 157 ("(55.) 1446 29 Novembre", `f136_copy1597.md`). The copy is
a decipherment made before this project, so f. 136 counts as read from an existing decipherment.
`import_peer.py` makes `f136_tokens.tsv`, `f136_signs.txt` and `f136_reading.md` from it.

Counts (`import_peer.py`): 562 tokens, 25 nulls and filler, 23 unread, 95.7% of non-null tokens read.

This folder's own pass (worker A, 28-29 Oct, made before the copy was known) is kept as `f136_passA.md`,
`f136_passA_reading.md`, `f136_passA_tokens.tsv`; it read 91.5% by sense, but only 68% of its words match the copy
(script over the two texts), so the pass with the copy replaces it.
