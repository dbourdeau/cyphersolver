# BnF italien 1583 f. 110 -- Filippo Maria Visconti to Francesco Sforza, Milan 1 Nov 1446 (cipher slip)

DECODE R7902, images I35645 P1 (recto, 41 cipher lines) and P2 (verso: 17 cipher lines at the top, the rest
show-through of the recto). Key R5323 (the same key is also on DECODE R1857 image 17, see `../key.md`).

**Transcription in use: `f110_transcription.tsv`**, pass 2 of the parallel session of 28-29 Oct 2026 (see
`../peer/WORKLOG.md`), one row per sign: folio (110 recto, 110v verso), line, position, key value (`i#2` = value i,
second homophone; capitals = word signs; NULL; ? unread) and a note with the sign's shape and its alignment with
the 19th-century copy in BnF ital. 1597 f. 123r-v (`f110_copy1597.md`). Each line was cropped at native
resolution and enlarged 3.5-8x. `import_peer.py` turns it into this folder's `f110_tokens.tsv` and
`f110_signs.txt` (signs are written as their key labels, so the distinct count is a count of key homophones).

**The 1597 copy is a decipherment of this slip, made before this project**, not an independent clear text: it writes
*gi* where the cipher has the group II + 3 (read *vuy*), *za* for the z sign + a, and leaves a blank marked "V+" at
both places of the name sign the key leaves blank. The transcription was aligned with it, so f. 110 counts as read
from an existing decipherment. Where the cipher and the copy differ the cipher's value is kept (`f110_alignment.md`).

Counts (`import_peer.py`): 2712 tokens, 23 nulls, 292 unread, 89.1% of non-null tokens read; recto 96.5%, verso
69.6% (the verso is cramped and its signs run together on the binarized DECODE image).

This folder's own pass (worker G, 29 Oct, without the copy) read 32% and is kept as `f110_passG.md`,
`f110_passG_reading.md`, `f110_passG_tokens.tsv`.
