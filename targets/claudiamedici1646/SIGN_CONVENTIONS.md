# Sign conventions (shape names only)

Frames 24793 and 24800 (Vlnas 2017, appendix zip P_lohy_A_a_B.zip), and the glossed siblings of the same hand.
The photographs are rotated 90 degrees; all crops were turned upright first. One token per sign, separated by
spaces; words are separated by ` | ` where the writer leaves a gap (the gaps are not always word breaks).
Plain Italian between cipher stretches is given in `<angle brackets>`.

| token | shape |
|---|---|
| `2` | plain figure two with flat base |
| `Q` | figure two with a closed loop at the left (a looped 2, like Armenian "Ձ") |
| `3` | figure three |
| `4` | figure four (open, cross-stroked) |
| `5` | figure five with a flat top stroke |
| `s` | small round s, often with a dot-like lower bowl |
| `7` | figure seven |
| `8` | figure eight |
| `g` | looped g / figure nine with a descending tail (the two forms are not kept apart) |
| `y` | small y with a descending tail |
| `D` | g-shape with a cross-bar or z-hook under the tail (Vlnas prints it as a pound sign) |
| `d` | round d with a looped ascender |
| `r` | small r |
| `c` | small c |
| `l` | tall stroke with a looped head and a foot (like an l or a long s) |
| `m` | small m |
| `I` | short upright bar, written double for zz |
| `x` | x or k shape with a small raised circle (Vlnas prints it as a Greek alpha with accent) |
| `K` | k-like sign with a tilde or bar on top (Vlnas prints it as a sharp s) |
| `+` | plus / cross |
| `A` | triangle, with or without a dot inside |
| `18`, `34`, `37`, `57` | two-figure groups, normally followed by a point |
| `iio` | the group "iio" followed by a point |
| `?` | sign not legible on the photograph |
| `X?` | (added after the independent check) a sign near the shape X but not equal to it; decrypted as X's value in round brackets and marked doubtful in the reading |
| `|f` | line-initial pen flourish (not a sign) |

Doubtful readings are written `a/b` (first = preferred shape). The shapes `5` and `s` are close on these
photographs; where the photograph does not separate them, the preferred shape is given with `/`.
