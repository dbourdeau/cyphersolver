# Philip IV → II marqués de Santa Cruz, autumn 1635: cipher key and two undeciphered letters

Material for https://github.com/dbourdeau/cyphersolver/issues/183 (catalogue 725–727). Source: AHNOB,
SANTA CRUZ, C.51, images on PARES (D.176–197: https://pares.cultura.gob.es/ParesBusquedas20/catalogo/description/12878263).

- `key_1635.md`: the September–December 1635 key, with the aligned cipher/decipherment pairs it was rebuilt from.
- `d179_cipher.md`: transcription of D.179 (Madrid, 1 Oct 1635, images 7–13), page by page, with clear passages.
- `d179_reading.md`: the reading of D.179 with the key; open groups marked.
- `d194.md`: transcription and reading of D.194 (San Lorenzo, 25 Oct 1635, image 59).
- `dec1635.py`: applies the key to the code blocks of a transcription file (`python3 dec1635.py d179_cipher.md`).

The working notes in `key_1635.md` and the transcription files grew over several passes; later sections
supersede earlier ones where they differ.
