# Reading: ASF MAP LXXII 333: read

ASF Mediceo avanti il Principato LXXII, doc. 333 (c. 417r, pos. 837): Francesco Pandolfini to Lorenzo de' Medici, "Parisijs die xxvij decembris M.D.xiiij" (27 Dec 1514), one cipher block of 3 lines. No decipherment of 333 itself, but the same news is given in clear in 332 (clear copy of the letter to the Otto of the same day). Key: `key_v6.json` (declared merge of the derived keys v5a and v5b of `key_v4.json`, see NOTES.md; **not measured**, the only measured key is v3, partial). Conventions (Daniel's): plain = certain; {x} = probable; [x] = restored; ‹…› = unresolved (tokens shown, `_` = space between tokens). Clear passages of the letter are given in [brackets] for context.

## Status

**Read: 29 cipher words, 28 certain, 1 probable, 0 restored, 0 unresolved = 100% read by sense.**
