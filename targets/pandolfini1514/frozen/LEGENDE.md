# Légende des jetons (transcription ASCII, protocole P01)
Un jeton = un signe : base[^exposant]. Exposant = chiffre(s) écrits au-dessus (voyelle), ou n / m.
Bases (formes) :
- chiffres arabes 0-9 tels quels (0 = petit rond ; 2 = « 2 » ; 3, 4, 5, 6, 7, 8, 9).
- lettres latines telles quelles : c (petit c), d (d rond oncial), r (r long/2-like minuscule), t (t barré), x, y, S (grand S/« 5 » à crochet), L (équerre), D (D renversé / « ꝺ »), F (F barré = et), M (M = non), E (E carré), T.
- W = « w » / « ꝡ » (signe-voyelle i) ; O = « ⊃ » (c renversé, signe-voyelle o) ; Q = φ (cercle barré, signe-voyelle e) ;
  Z = « ꝛ » trait suivi d'un 2 couché (« -2 ») ; A = triangle Δ ; H = « # » (double barre croisée) ; J = « ʄ » (long s/f à boucle) ;
  V = « ∧ ».
- Groupes de nomenclateur entre points : .2. .4. .5. .6. .24. .26. …
- « ? » suffixe = jeton douteux ; [mots] = clair dans la lettre.
