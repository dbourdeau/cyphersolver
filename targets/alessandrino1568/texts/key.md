# Key of Cardinal Alessandrino's ciphers to the nuncio in Spain, 1567-69 (Spagna 6/I, 6/II)

Base: George Lasry's reconstruction on DECODE (DOC_R9x_D32xx, 24 Oct 2020), as coded in `decrypt.py`. Extended on
22 Oct 2026 (reread batch "aless") from the contemporary decipherments of R94 (f. 45r), R95 (f. 58r) and R100 (f.
280r), as coded in `reread_aless_decode.py` / `reread_aless_align.py`. "dec." = attested by a decipherment.

## Letters (polyphonic: each figure two letters)

| figure | letters | added 22 Oct 2026 |
|---|---|---|
| 1 | u (v) / t | |
| 2 | i / m | |
| 3 | f / g | |
| 4 | a / l | |
| 5 | o / s | |
| 6 | e / n | |
| 7 | d / r | |
| 8 | b / c | |
| 9 | p / z | also the syllable **con** (dec.: concesso, conscientia, contenta, conprende) |
| 0 | null | **dotted 0 = z** (forze, terzo, patienza, senza) |

No h, no q: "qu" words are codes or 3 0 9 (qua); "chi" is written with the code for "che" (2 0 9: chinea, Chiesa,
chiarire). A doubled letter is enciphered once.
