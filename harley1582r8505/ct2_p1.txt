# Format:  1.<n> | clear before | SIGNS space separated | clear after      [y=<thumbnail y>]
# '?' = that sign is doubtful.  ' / ' = a visible gap.  #81 = the number written .81.
# Sign names follow signs.md as revised by the f.264v and f.263v passes (see the headers of
# ct2_p4.txt and ct2_p3.txt).  In particular :2 :3 :4 are the DOT GROUPS = m (a letter, not
# punctuation); eq = short vertical with a dot cluster at its upper right = f; phi = closed oval
# pierced by a long stem = b; f = tall long-s, hook at the top only = u; E3 = two-bowled epsilon
# = s; E = lunate epsilon = a; T = top bar to the LEFT + loop at the foot = u; b = loop at the
# foot, no top bar = n; hg = hourglass (the X is CLOSED BY A BAR ACROSS THE TOP) = p; Br/Usq = g;
# Pi = Pi with the bar on TOP = o; Usq = the same shape with the bar at the BOTTOM = g.
# The decode of each line is given in the comment below it.
