The Key Web

A cipher is rarely read on its own. A key rebuilt from one letter's margin is tried on its unread siblings. A contemporary key turns up filed under the next record number. A table published by Lasry or Tomokiyo is turned on a letter they never saw. Each gold key below is linked to the letters it read. Letters sit roughly by date from left to right. Hover to trace a key, click for the write-up, drag to rearrange.

The key web

Pick a node

Hover a gold key to see every letter it read, or a letter to see which keys read it. The keys with the most links are the ones that did the most work: a key made for one letter that went on to read the rest of its series.

About the data

Every link is taken from an explicit statement in the target's notes: that a letter was read with a named key, unchanged or adapted, or that a key was rebuilt from that letter's own material. Links are not inferred from resemblance. A key that read only one letter is still shown, because where it came from is part of the story. Several of George Lasry's tables for the French correspondence of the 1520s and 1530s appear as one node. The file is keys.json.
