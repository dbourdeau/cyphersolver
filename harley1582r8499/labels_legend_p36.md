# Labels in transcription_v2_p36.txt (pages 3 and 6)

Each label replaces an ambiguous token of transcription.txt after checking the line crops (img/L/p3_NN_K.jpg,
p6_NN_K.jpg) and the key (key_null.jpg, key_R354.md, key_merged_p36.md). Values are given only where the key or
context supports them; "?" = not established. Tokens not listed are unchanged from transcription.txt.
