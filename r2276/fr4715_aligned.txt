# BnF fr. 4715 f. 2r (Gallica btv1b52509819x, canvas 17): Cardinal de Guise to Nevers, Soissons, 6 Oct 1586.
# Nevers-Piles cipher with the contemporary decipherment written ABOVE each cipher line (interlinear).
# Aligned 23 Sept 2026 from img/f4715_17.jpg (crops: img/f4715_crop.py, f4715_line.py, f4715_zoom.py; bands img/f4715/L*.png).
# Values: u/v and i/j are not distinguished (v written as u, je as ie).
# Format: L<n> | cipher signs (R2276 labels) | interlinear | sign=value pairs ("x=" = null; "?" = value not settled)
# Labels are those of LABELS.md / READ_BRIEF2.md. NEW labels for glyphs of this hand not in the R2276 list:
#   Jy  large initial long-s (∫) at the head of the letter = "jay" (code)
#   om  ω-shaped sign (like "cs"/"ɷ" joined, rounded) = a  (very common here; not in Tomokiyo's table)
#   Dz  small triangle Δ = z
#   Om  Ω-shaped sign (horseshoe with feet)            = avec (interlinear writes "aut" = auec; 3 times)
#   Hb  box open with a bar under it (Ħ)               = n
#   o~  small o with an overline (ō)                   = f(aict) (satisf-ō)
#   ss  small s-like sign in "l'ay" (after + v) = y
#   TT  bold ꟿ (double loop, "ꝏ" heavy)                = tousiours (code)
#   s   (this hand) plain small s-shape, not ≠ = i (suis, supplie, compagnie); NOT the R2276 ꝺ-with-superscript-t
#   Dn  ʋ with a hooked top (Ʋ), taller than v = donner / donné (code; 2x L16)
#   Zd  the γ/ψ-shaped e-sign (label z) with a dot above (ẏ) = e
#   3L  large ʒ with a long hooked descender (ℨ-like), bigger than ordinary ʒ = part (code; 2x: 'feray part', 'les particularitez')
#   Xm  curly x crossed by a straight horizontal bar (ꭗ̶) = m (madame, dame); distinct from X (curly x, hooks, = e). Probably what R2276 calls x or X.
#   mt  m with a long tail on the last leg (ɱ) = o; plain m = r
#   H+  box with a vertical bar through the top (Ⱨ, "⊞ open") = n (nous, noz); once under interlinear "mr". Candidate for R2276 N (boxed cross)?
#   Sw  large swash S-stroke (as in L22 before ẋ) = ?
#   Hm  box with a bar across the middle (⊟) = r (retourne, revenir); in L14 paired with ⊡
#   s^l small s with superscript l = les? (interlinear "le[s]") 
#   O   (as R2276) small s/ꝺ with a raised o to its right ("sᵒ") = faire (L17 "et faire observer"; image checked)
#   Jb  long s with crossbars/overline (ʃ̄, "ξ")         = le (code)
#   b6  large 6-shaped b (б)                           = ? (in "cest affaire" group)
# Mapping of this hand's glyphs to labels: ⊡ box with dot = H (r); plain box □ = R (n); ⋕ (box with bars) = #;
#   θ = o (e); ꭗ curly x = X (e); ψ / γ-with-descender (looks like 'y', = ꝝ) = z (e; once alone = luy, L11); 8 = 8 (c); W = w (c); ɔ = c (u); φ = f (u/v); b = b (u/v);
#   ce/æ ligature = e (o, pour); small o = 0 (p); uq = P (p); ∇ = V (m); v = v (a/m); - = - (a); ꝺ/δ = d;
#   + = t (l); crossed ꝏ = l (l); m = m (r); q-shape with straight tail (ꝗ) = g (s or i); flat Ƶ = 2 (b); 9 with curl = 9 (i); ∞ loop = Q (i);
