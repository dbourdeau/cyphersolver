# Moncada 1524 key, rebuilt from the letter against the CODOIN XXIV decipherment

Sign names as in `ct.txt`. Built by aligning each cipher run with the 1854 printed text (`em_align.py`, then by hand
where the transcription is doubtful). Homophonic substitution of invented signs for Spanish letters; no syllable
signs; a double cross (ǂ) written after a base sign makes a new sign; a few code groups built from Latin letters.

Code and word signs: `lay` = yo (twice), `ne` = duque (in "el duque de Genoua"), `Q#` (Δǂ) = el.
Open code groups: `=D.` (before the ciphered "duque de Borbon"), `P#D` (opening the credence), `=P#D.f` (after
"me ha significado"); `99` at the end of cipher line 2.

Irregular spots: "diziendome" is written f# 3 S# z# L p # H b L, with ʒ (normally u) for the first i; "para ello"
is w z# E 8 N H (six signs for eight letters); "galeras" in cipher line 8 has five signs. These are the
encipherer's slips or the image's limits (the DECODE scan is 970 px wide), not open readings.
