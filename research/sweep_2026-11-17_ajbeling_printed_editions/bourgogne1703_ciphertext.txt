# How it was made: two transcribers (AI agents, working apart; the second worked from the last line to the first)
# read the numbers from the strips without seeing each other's work or any OCR. Compared position by position, the two
# readings agree at all 353 numbers; neither marked a digit as uncertain. The Internet Archive OCR agrees once footnote
# calls are removed. No person has checked the transcription against the print.
#
# Printing notes: each number is followed by a period and a space, run on with the clear words. Removed as footnote
# calls: the "1" after the first number of letter X (202, note 1 on p. 21) and the "2" after the first number of
# letter XI (256, note 2 on p. 26; HathiTrust's OCR fuses it as "2562"). Read as numbers: "33'6" on p. 21 (an
# apostrophe-like mark inside 336, a value that occurs three more times), "325," and "44," (commas for periods). A
# small reddish dot after 229 on p. 21 is a mark on the scan, not type. No word division, no superscripts.
#
# Counts: 353 numbers, 126 distinct values, range 1-406; letter X 213 (106 distinct), letter XI 140 (78 distinct),
