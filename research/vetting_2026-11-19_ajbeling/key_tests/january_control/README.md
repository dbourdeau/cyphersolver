# Positive control using a letter with a known decipherment

On 4 January 1585 Charles Paget wrote to Mary, Queen of Scots. TNA SP 53/15 f. 6r has the cipher, and f. 7r has its period decipherment. Tomokiyo identifies the Chartley table SP 53/22 f. 47 with this letter. The short Paget–Mary sheet (old 97a) preserves the same core system and a narrower set of entries. This control tests whether the September study’s exact visual matching procedure recognizes known material using the same short key panel. [Cipher original, scan 16 right](https://link.gale.com/apps/doc/MC4307883976/SPOL) · [Contemporary decipher, scan 18 right](https://link.gale.com/apps/doc/MC4307883977/SPOL) · [DECODE record](https://de-crypt.org/decrypt-web/RecordsView/3853)

Two sign readers independently inspected a masked strip of the first complete cipher row, without the separately transcribed plaintext or value labels. They recorded 102 and 103 sign positions respectively. The alignment gave 109 candidate positions. Only eight had the same key tile at high confidence in both passes. There were zero adjacent pairs and zero recovered reference characters in eligible runs. All 1,000 shuffled controls tied at zero. The threshold required 40% coverage, five adjacent pairs and a reference match above every shuffled key. **The positive control missed.** A third reader independently transcribed the opening from the separate period copy. Abbreviations were retained, and the salutation was excluded.

For diagnosis only, 96 positions had reciprocal coordinate matches. The readers gave the same tile at 55 of those positions when confidence was ignored, compared with the eight qualifying positions. These lower-confidence observations were excluded under the plan. No alternative plaintext or re-scored historical test is claimed. The terminal archival foliation stroke touched the last sign. Differences between the short key, the fuller sheet and the scribe’s execution may matter. This test demonstrates that sparse strict matching can arise even on a document with a supported key attribution. The September tests establish zero new words, and they cannot eliminate a related system.
