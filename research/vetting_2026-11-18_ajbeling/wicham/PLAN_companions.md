# Do all the three-digit names in the July and August companions use the same table?

The new held-out manuscripts are the July and August companion letters in the same archival packet, SP 12/283a ff.154–155, Green 75.III and IV. The person setting this plan has seen Green’s abstracts and the source table and has not inspected the manuscript text of these two letters. The September transfer already missed. Two blind transcription readers have been assigned the new letters with no key. No trial on these companions or change to the previous evaluation is allowed before this plan is frozen.

At each physical location accept only the identical three consecutive numeral shapes qualified as a definite cipher number by both readers. Match with adjacent clear words, position and order. Any conflict, question, date, ordinary quantity, marginal date, prefix with uncertain division or nonnumeric sign is a hole. Exclude two-digit place numbers, dotted alphabet numbers, and these four-digit/longer groups. Do not expand abbreviations or resolve repeated key digits. Use only the 65 accepted exact literal rows of 75.V from V_names.tsv, SHA-256 4cf0357b4d64afc96769d1b5e8bc189c515bb39fc6d769e882f4c7aafe1d932e. One table and one direction. Give each consensus triple its historical key value if available; retain holes otherwise.

Score the number of distinct prespecified name concepts recovered under their correct letter, up to eight. The concepts are taken from Green’s summaries on pp.174–175: for III, Admiral, Norris, Essex, Cumberland; for IV, Jaques, Owen, Essex, Ross. Compare case-folded complete tokens, dropping accents, punctuation and case. Admit these ordinary written variants only: admiral/admirall, Norris/Norreys, Essex, Cumberland, Jaques/Jacques, Owen, Ross/Rosse. Presence in the correct letter suffices; the same concept cannot score twice in one letter. Pass requires at least three of the eight, at least one in each letter, and a corrected probability at most .01. Seed Python random.Random(15970720), permute the 65 values among all fixed number labels as in the September test, 1,000 times; both letters share each permutation. Count controls with a total at least the observed total; report (count+1)/1001. If a letter has no three-digit cipher numbers, give it score zero; if both have none, every control scores zero and the result is a miss. No replacement by different letters or other alphabets, and no second run. No whole-word count for an abbreviation or for a mixed agreed/disputed group. Cite the prior printed reading for any agreement.
