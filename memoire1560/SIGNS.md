# Sign code for BnF fr. 3157 ff. 152r-156v ("Mémoire en chiffre du XIIe décembre 1560")

The cipher is written in a cursive pseudo-script with words separated by "/". Transcribe one ASCII
character per sign, words separated by a single space, one manuscript line per output line.

| code | sign |
|---|---|
| x | the x-shaped sign (the most common sign; it ends many words: "hx", "Wx") |
| r | a smaller, rounder r-/ɤ-like variant of x, only when it is clearly different from x |
| m | three minims joined (like m / ııı) |
| n | two minims joined (like n / u / ıı) |
| N | и-shape: two minims joined by a diagonal (like reversed N) |
| i | a single minim (with or without a dot) |
| H | H/н-shape: two uprights with a cross bar (like # with a slanted bar) |
| z | small z (sits on the line) |
| 3 | ʒ: z with a tail below the line |
| o | o |
| : | a pair of dots (":" or "··"), one sign |
| h | h-shape: tall ascender with an arch |
| W | ω / "co" / "bo": a double loop |
| s | long ſ descending below the line (with or without a hook on top) |
| S | a looped ascender fused with ſ ("δſ", "Sſ") |
| D | ‡: cross with two bars, descending (double dagger) |
| + | a small plus / cross on the line |
| t | t |
| f | f (tall, crossed, descending) |
| p | p |
| 7 | 7 |
| Q | any sign drawn inside a circle (⊕, circled m/n) |
| T | θ: circle with a bar through it |
| d | δ: small loop with a curved ascender |
| g | g |
| c | c |
| b | b |
| l | a tall straight vertical stroke (as the first sign of f.152r) |
| a | a |
| 4 | a 4-shape |
| ? | an illegible sign |

Struck-through signs: put them in square brackets, e.g. `[zox]`. A word that runs on to the next
line: end the line with `=`.

Worked example, f.152r first lines (approximate):

    lzxNNHzoxmm [blot] Wxm hxsxDxsm +hioxsQDmmmxppsfxm
    Tzox xxio:zmm + [zox] zo:mmQsx Ss+xhxzos Wxnn
    D77+isxm hxH+shxft 3xxQ hDnnf:s3xzo hx pp+W
